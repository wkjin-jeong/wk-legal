# 미해결 표식 어휘

아래 표기만 쓴다. `verify`가 이 문자열을 그대로 세므로 설명 문장에서는 표식명을 쓰지 않는다(front-matter의 키는 `verify` 출력의 키를 그대로 옮긴다). 남은 표식은 front-matter `미해결표식`에 종류별 개수로 적는다. 완성 여부는 SKILL.md §2 "완료의 모양"이 정한다(`[마스킹]`은 해소 대상이 아니라 개수만 적는다).

| 표식 | 붙는 경우 | 해소 |
|---|---|---|
| `[불명확: …]` `[판독불가]` | 변환 표식의 승계. 이 표식이 낀 금액·일자는 단정하지 않는다 | 원본 PDF 해당 쪽의 재판독(변환 모델과 다른 모델이면 독립성이 있다) |
| `[마스킹]` | 가림의 승계. 재판독해도 나오지 않는다 | 해소 대상이 아니다. 추정으로 채우지 않는다 |
| 면수 확인 필요 | 면수 없는 쪽(앞뒤 면수 사이 구간으로 귀속) | 원본에서 면수 확인 |
| 원본 PDF 확인 필요 | B·C 등급 입력의 좌표·인용·금액·일자, 원본 미보유 기록, 변환본에 `[도면]`·`[사진]`·`[그림]` 묘사만 있는 문건, 전사 의심 | 원본 확보·대조 |
| 변호사 확정 필요 | 증거 단위 배정의 추정·미배정, 파일명에서 읽은 호증 번호, 추정한 문건 경계·인물 병합·분류 | 사용자 확인 후 매니페스트·카드 갱신 |
| 행 좌표 필요 | 쪽·행 단위 좌표가 필요한 정밀 다툼(내용부인 등) | 원본 PDF에서 행 확인 |
| 프레임 필요 | 프레임 문건(소장·준비서면·증거설명서·기존 인부 내역)이 없어 비워 둔 칸(입증취지·증명취지·쟁점 사실) | 프레임 문건 확보 |
| 확인 필요 | 그 밖의 미확인 사실 | — |
| `[법령 미확인]` | `ko-law-api`로 확인하지 않은 조문 포인터 | 조문 확인 |
| `[판례 미확인]` | `shared/판례-인용-정책.md` | 같은 정책 |
