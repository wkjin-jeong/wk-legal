# 입력 규격·반입·게이트

## 1. 입력 계약

변환기는 쪽에서 눈으로 확인되는 것만 옮긴다. 사건번호·문서 종류·증거번호는 변환본에 없다 — 구조화는 전부 이 skill의 일이다. 아래 계약만 맞으면 어떤 변환기의 산출물이든 읽는다.

| 항목 | 규격 |
|---|---|
| 폴더 | `{원본 stem}/` 아래 `pages/page_NNN.md`(원본 1쪽 = 1파일, 3자리·1000쪽 이상이면 4자리), `_index.md`, 읽기용 파일(`{stem}_통합.md` 또는 `sections/`). `_work/`는 작업용이며 남아 있다는 보장이 없다 |
| front-matter | **4키뿐**: `pdf_page`(= 파일명 번호), `printed_page`(인쇄되었거나 도장으로 찍힌 쪽수. 없으면 null, 보간 없음. 면수 도장이 있는 기록에서는 도장이 우선이고 도장 없는 쪽은 null), `heading`(그 쪽 **첫머리**가 속한 문서 제목. 제목 줄에 인쇄된 회차·진술자는 포함), `notes`(회전·양면 스캔 등) |
| 양면(2-up) | `printed_page`는 왼쪽 면, `notes`에 `양면, 우측 면수 N`, 본문은 `[좌]`·`[우]` 줄로 나뉜다 |
| `_index.md` | 현황 3줄(원본 파일명·총쪽수 / 변환 쪽수·누락 / 판독불가·불명확 표식 개수) + 구간표 `시작pdf \| 끝pdf \| 인쇄면 \| 제목 \| 파일 \| 비고`. **비고 칸은 사용자가 증거번호 등을 적는 자리**다 |
| 본문 | 요약·해석·교정 없음. 인쇄상 줄바꿈은 문단으로 잇고 쪽 끝에서 끊긴 문장은 끊긴 채 둔다. 매 쪽 반복되는 머리말·꼬리말과 `printed_page`로 옮긴 쪽번호는 빠진다. 그 밖의 쪽번호(조서의 `- 6 -`, 전자문서 스탬프의 `1 / N`)는 본문에 남는다. 열람정보는 첫 줄 `<!-- 열람정보: … -->`. 쪽마다 `# 문서 제목` 하나, 쪽 중간에서 새 문서가 시작하면 그 자리에 `# 새 문서 제목` |
| 고정 표식 | `[판독불가]` `[판독불가: 약 5줄]` `[불명확: 추정]` `[날인: 문구]` `[스탬프: 문구]` `[서명]` `[무인]` `[수기: 내용]` `[사진: 설명]` `[도면: 설명]` `[그림: 설명]` `[빈 페이지]` `[강조: 내용]` `[마스킹]` `[좌]` `[우]` `~~말소~~` `[v]` `[ ]` |
| 가림 | 글자로 가린 것(`611207-1******`, `김○○`)은 원문대로, 덮어 가린 것은 `[마스킹]`. `[판독불가]`와 다르다 — 재판독해도 나오지 않는다 |

읽는 순서: `_index.md` → `index`가 만든 작업 색인 → 필요한 `pages/page_NNN.md`만 부분 읽기. 읽기용 파일은 사람용이다(절 경계에서 쪽 중간이 나뉜다). 변환본에는 쓰지 않는다. 비고 칸도 읽기만 한다.

## 2. 게이트 불변식(`gate`)

1. `_index.md` 현황: 변환 쪽수 = 총쪽수, 누락 "없음".
2. `pages/` 파일 수 = 총쪽수, 번호 연속, `pdf_page` = 파일명 번호.
3. front-matter가 정확히 4키. 키 구성으로 세대를 판정한다 — 4키 = 현행, `record_page`·`doc_title`·`evidence_ref`가 있으면 구 규격(A′), front-matter 없음 = 규격 밖, 쪽 파일 자체가 없으면 증거 단위 md(구세대). 뒤의 둘은 입력으로 잡지 않고(`gate` 오류, `index` 거부) 세대와 함께 보고한다.
4. `printed_page`가 정수 또는 null.
5. (경고) `_index.md`가 `pages/`보다 오래됨 → `index`가 재구성한 구간을 쓴다고 알린다.
6. (경고) 표식 개수의 차이, 고정 표식 밖의 가림·판독 표기.
7. (경고) 폴더명 NFC, 경로 1,024바이트, 분석 폴더 안의 동기화 충돌 사본, 매니페스트에 적힌 원본의 부재.

B 등급 입력의 `[가림]`·`[블러]`·`[이름가림]`·`[모자이크]`·`[비식별화]`·`■■■` 등은 `[마스킹]`으로 읽는다.

## 3. 반입 규약(`import`)

1. 대상은 `pages/`·`_index.md`·읽기용 파일이다. `_work/`는 반입하지 않는다.
2. 저장소 배치는 `{저장소}/{stem}/`. 여러 권이 한 묶음이거나 stem이 겹칠 때만 `{저장소}/{묶음}/{stem}/`(`--bundle`). 분류별 하위 폴더를 두지 않는다.
3. 원본의 상대 경로·크기·sha256(`--original`), 출처·반입일, 분류, 변환 모델은 **매니페스트에만** 적는다. 산출 폴더 안에는 아무것도 더하지 않는다.
4. 같은 문서는 한 번만 변환한다. 증거로 승격되거나 제출 후 사본(전자소송본)이 생기면 매니페스트의 증거번호·`사본`만 더한다. 같은 문서라는 연결은 사용자가 확인해 준다.
5. 재반입(재변환·누락 보충)은 `--replace`로 폴더를 통째로 바꾼다. 이후 `index` → `coverage`가 원문이 바뀐 카드를 가려낸다.
6. 수동으로 넣은 변환본도 착수 시 `gate`가 같은 검사를 한다. 출처 칸만 빈다. 이미 저장소 안에 있는 변환본은 `import`하지 않고 `gate` → `index`로 등록한다(`import`는 원천과 대상이 같거나 서로 포함되면 거부한다).
7. 원본이 옮겨졌으면 `locate`(stem → 크기 → sha256). 원본 폴더 전체에 내용 검색을 하지 않는다.

## 4. 변환본을 읽을 때의 함정

- **`printed_page`의 뜻이 기록마다 다르다.** 형사 기록에서는 기록 전체에 이어지는 면수 도장, 민사 서증·단일 문서에서는 그 문서의 쪽번호(문서마다 1로 돌아감)일 수 있다. `index`의 추정은 초안이다 — 장이 나뉜 단일 문서도 "연속 증가"로 나온다. 확인해 매니페스트에 `기록 면수` 또는 `문서 쪽수`로 적는다(`assign`은 `기록 면수`인 record만 쓴다).
- **`heading`이 문서 제목이 아닐 수 있다.** 공문의 레터헤드(회사명)·법원명이 잡히거나, 제목 없는 사진·도면에서는 파일명과 같은 문구가 들어 있다. 카드의 `제목`은 본문을 보고 정한다.
- **변환 품질이 의심되는 record**(양면 스캔에서 쪽당 분량 급감, 조문 번호의 불연속, 리터럴 `\n` 잔존, 같은 표가 record마다 다르게 전사)는 등급 A·표식 0이어도 나온다. 고치지 않고 `주의메모 후보:`와 "원본 PDF 확인 필요"를 단다. `index`는 본문이 같은 쪽을 가진 record 쌍을 알려 준다(중복 제출 또는 변환 중복).
- **`heading`은 첫머리 기준이다.** 쪽 중간에서 시작한 문서는 `heading`이 한 쪽 늦게 바뀐다 — 본문의 두 번째 `# 제목`을 본다.
- **같은 양식 제목의 문서가 연속하면 한 구간으로 합쳐지고, 제목이 쪽마다 흔들리면 쪼개진다.** `references/02` §2의 보조 단서로 바로잡는다.
- 매 쪽에 `# 문서 제목`이 반복된다 — H1은 문서 시작 신호가 아니다.
- **줄바꿈이 문단으로 이어져 행 좌표를 셀 수 없다.** 쪽·행 단위 좌표가 필요한 정밀 다툼(내용부인 등)에는 "행 좌표 필요"를 달고 원본 PDF 확인을 안내한다.
- **표**: 쪽이 넘어가면 머리글이 다시 나오고(한 행이 쪽 경계에서 셀 단위로 나뉘기도 한다), 소계·합계 행이 표 안에 있으며, 병합 셀은 첫 행에만 값이 있다. 금액은 한 자리라도 불확실하면 항목 전체가 `[불명확: …]`이다.
- **대화 캡처**: `| 시각 | 발신자 | 내용 |` 표. `(본인)`이 누구인지는 캡처한 사람을 확정해야 안다. 쪽 첫머리에 날짜 줄이 없으면 앞쪽에서 이월한다. 날짜 줄보다 앞선 말풍선은 일자 미상으로 두고, 쪽을 넘는 말풍선의 시각은 마지막 조각에 붙는다. 중복 말풍선은 지워지지 않았다.
- 고정 표식 밖의 대괄호(`[지번]`, `[121-801]`, `[ 합 계 ]`)는 원문 표기일 수 있다. 변환 표식으로 세지 않는다. `[직인: …]`·`[인영: …]`·`[인]`은 `[날인]`의 변형으로 읽되 날인 유무를 단정하지 않는다. 닫히지 않은 대괄호는 전사 의심이다.
- **`[수기: …]`의 작성 주체**는 제출자·수사관일 수 있다. 문서 작성자에게 귀속시키지 않는다.
- 페이지 경계에 걸친 문답의 좌표는 `12-13`으로 적는다.
- 열람정보 주석의 제출자는 민사 제출 당사자의 단서다. 폴더명(원본 stem)은 사건 메타의 출처다(`references/02` §4).
