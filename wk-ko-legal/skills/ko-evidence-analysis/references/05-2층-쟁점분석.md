# 2층 — 쟁점 분석

## 1. 산출물 front-matter(drafting 인계 계약)

```
---
산출스킬: ko-evidence-analysis
층: 2
산출물: 공소사실-분해표
모드: B
기준일: 2026-06-10
입장: 피고인
입력: [{record_id: 증거기록_1, 등급: A}, {record_id: 형사/증거기록_별권1, 등급: B}]
미해결표식: {확인 필요: 0, 면수 확인 필요: 3, 원본 PDF 확인 필요: 12, 변호사 확정 필요: 4, 판례 미확인: 0}
판례확인: {검색원: …, 확인일: …, 변경확인: …, 최신성: 미검증}
---
```

`모드`가 없는 산출물(증거 목록·처분사유 대조표·공백 계획)은 `모드: 해당 없음`. `입력`은 record가 많으면 `{범위: 갑3~갑31, 건수: 28, 등급: A}`처럼 줄인다. `미해결표식`은 발생 횟수이고 `verify` 출력의 `파일별_표식`을 옮긴다(`references/06`의 표기만 쓴다 — "의뢰인 확인 필요" 같은 변형을 만들지 않는다). 0이 아니거나 B·C 입력이 있으면 본문 첫머리에 "미완성 — 확인 필요 사항 있음"을 적는다. 판례를 확인하지 않았으면 `판례확인: 해당 없음`. 착수 게이트에서 가정한 것은 본문 첫머리에 "가정"으로 적는다. 파일명은 `{산출물}_{YYYYMMDD}[_rN].md`(산출물명의 공백·가운뎃점은 하이픈).

## 2. 산출물별 열 구성

모든 행은 카드 키와 증거 ID를 참조하고, 인용은 원문 쪽에서 다시 따 `"…"{{p:갑7#쪽}}`(증거번호 별칭 또는 record_id)로 적는다. 남의 말을 옮긴 진술은 안쪽만 인용하고 `(전언)`과 옮긴 사람을 적는다. 프레임 문건이 없으면 모드 C의 쟁점 사실은 기록 안에서 진술이 부딪치는 지점으로 잡고, 입증취지·증명취지 칸은 문건이 직접 보여 주는 사실까지만 적고 "프레임 필요"로 둔다. 가지번호로 쪼개진 같은 양식의 증빙은 한 행으로 묶어도 된다(묶었다고 적고, 가지별로 의견이 갈리면 나눈다). 같은 원본으로 보이는 두 변환본(양측 제출·재제출)의 기재가 다르면 변환 이상을 먼저 의심하고 원본 대조 전에는 판단을 보류한다. 확인하지 않은 조문 포인터에는 `[법령 미확인]`을 단다. 항소심이면 1심의 인부 내역과의 정합을 확인 사항으로 올린다.

| 산출물 | 모드·분야 | 열 구성·요점 |
|---|---|---|
| 요건사실 매핑표 | B·민사·행정 | `요건사실(항변 포함) \| 증명책임 \| 유리한 증거 \| 불리한 증거 \| 다툼 여부 \| 공백`. 증명책임의 분배는 조문·판례로 확인한다 |
| 공소사실 분해표 | B·형사 | `구성요건 요소 \| 검사 측 증거(목록ID·순번·권·면수) \| 동의 여부 \| 다툼 차원(증거능력/증명력/법리) \| 반박 증거`. 공소장·범죄일람표의 번호 체계를 행 키로 쓴다 |
| 진술 변천·모순표 | C·공통 | `쟁점 사실 \| 진술자 \| 1차 진술 \| 2차 이후 \| 법정 진술 \| 배치되는 객관 증거 \| 이해관계 \| 판정(일치/차이)`. 각 진술에 일시와 매체(조서·문자·통화 녹취·사실확인서)를 적는다. 일치하는 진술도 행으로 둔다. 반대신문 3단(외곽 사실 고정 → 모순 노출 → 결론 압박)에 바로 들어가는 순서로 정렬한다. 탄핵의 4단(진술 변천 → 객관 증거와 배치 → 이해관계 → 내용의 비합리성)은 `ko-criminal-drafting/references/06-쟁점별-논증구조.md`와 같다 |
| 증거능력 스크리닝 | D·형사 | `증거 ID \| 증거 종류 \| 적용 조문 \| 요건별 충족 여부(형식 사실의 좌표) \| 동의 여부 \| 다툼 가능성`. 검토 순서는 위 06과 같다. 조문은 `ko-law-api get-asof`로 확인한다(형사소송법 제312조처럼 시행일에 따라 요건이 다른 조문이 있다). 의뢰인 제출 자료의 수집 적법성(타인 간 대화 녹음 등), 감정서·포렌식 보고서의 대상물 동일성·선별 절차도 본다 |
| 상대방 서증 인부 검토표 | E·민사 | `호증 \| 서증명 \| 문서 성격 \| 인부(성립인정/부인(이유 필수)/부지/보류 — 의뢰인 확인·원본 대조) \| 근거 형식 사실(좌표) \| 원본 존재 \| 날인사실 인정과 인영 인정의 구별(2단의 추정 중 어느 단계를 다투는지) \| 증명취지 부인 \| 증거항변 \| 부분 인부`. 표 아래에 **불리한 기재**와 **원용할 수 있는 기재**(상대방 서증 안의 유리한 기재)를 보조표로 둔다 |
| 처분사유 대조표 | 행정 | `처분서의 처분사유 원문 \| 피고의 소송상 주장 사유 \| 기본적 사실관계의 동일성(추가·변경 여부) \| 관련 증거`. 처분 후 생성된 증거에는 기준시 표지를 단다 |
| 증거 목록 | 민사 | 증거설명서 6열에 맞춘다: `호증 \| 서증명 \| 작성일자 \| 작성자 \| 입증취지 \| 비고` |
| 공백·보강 계획 | 공통 | `공백(요건·쟁점) \| 필요한 증거 \| 수단 \| 제약`. 수단: 열람·등사 추가 신청(원천현황의 없음·일부), 증거보전, 문서제출명령, 문서송부촉탁, 법원 밖 서증조사, 사실조회, 금융거래정보·과세정보 제출명령, 감정·검증, 증인진술서, 당사자신문, 행정심판기록 제출명령, 정보공개청구. 제약: 모색적 증거신청의 한계, 실기한 공격방어방법 각하. 분류가 "자료"인 것 가운데 제출 후보도 가리킨다 |

## 3. 방법론의 근거

이 skill에는 방법론의 내용을 옮겨 두지 않는다. 필요할 때 확인한다.

- **조문**: `ko-law-api`(형사는 `get-asof`).
- **판례**: `shared/판례-인용-정책.md`. 신빙성 판단·사실인정처럼 사실관계가 비슷한 사례가 필요한 쟁점은 하급심 비중이 크다.
- **문헌**(`shared/LLM-wiki-연동-정책.md`의 존재 게이트 통과 시, 없으면 조용히 생략): 민사 서증·인부·증거항변·문서제출명령·신문은 법원실무제요 민사소송 III의 증거 편을 연동 정책 §3의 레시피로 찾는다. 행정(증명책임, 위법판단 기준시, 처분사유 추가·변경)은 카탈로그에 행정소송 문헌이 있을 때 같은 방식으로 찾는다. 형사는 문헌이 없을 수 있다 — 조문·판례와 `lbox-commentary-search`에 의존한다. 문헌의 조문·판례는 재확인한 것만 쓰고, 문헌 원문을 산출물에 길게 옮기지 않는다.

## 4. drafting 접합점

| 분석 산출물 | 인계처 |
|---|---|
| 증거능력 스크리닝 + 동의 여부 | 형사 공판의견서 별지 증거의견 표·입증계획(`ko-criminal-drafting/references/03`) |
| 진술 변천·모순표 | 형사·민사 신문사항, 변론요지서 |
| 공소사실 분해표 | 공판의견서·변론요지서 |
| 증거 목록(6열) | 민사 증거설명서, 입증방법 목록 |
| 인부 검토표 | 민사 준비서면(서증 인부) |
| 처분사유 대조표·타임라인 | 행정 소장·준비서면 |
| 공백·보강 계획 | 절차 신청서(문서제출명령·송부촉탁·사실조회 등) |

분석 산출물에서 온 사실은 "기록에 그렇게 적혀 있다"는 사실이다. 그 내용이 진실이라는 것과 다르므로 drafting에는 **기재 표지 + 출처 문건 종류**를 그대로 넘긴다.
