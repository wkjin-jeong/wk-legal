# 형사 기록 경로

증거목록·권 체계·목록 ↔ 기록 대조는 형사 기록 전용이다. 민사·가사·행정의 증거목록은 법원이 작성해 법원 기록에만 편철하므로 당사자 자료에는 없다.

## 1. 증거목록 파서(`evlist`)

증거서류 등 목록은 14열이다(「형사공판조서 중 증거조사부분의 목록화에 관한 예규」 재형 2003-2): 순번·작성·쪽수(수)·쪽수(증)·증거명칭·성명·참조사항 등·신청기일·증거의견 기일·증거의견 내용·증거결정 기일·증거결정 내용·증거조사기일·비고. 입력은 `heading`이 증거목록인 쪽의 표이고, 여러 쪽의 표를 순서대로 이어 읽는다. 머리글은 부분일치로 찾는다.

파서가 처리하는 것 — 결과(`_작업/증거목록_{ID}.jsonl`)를 읽을 때 알아야 할 것:

| 원문 | 처리 |
|---|---|
| 쪽수란의 "제3권"·"별권 5" | 목록에 권 열이 없다. 이 줄에서 권이 바뀌고 뒤의 행은 숫자만 적힌다(상태 기계). 첫 전환 전은 "본권". 순번이 있는데 면수가 없으면 `권전체` |
| `74~84` | 범위(`끝면_기재: true`). 그 밖의 `끝면`은 같은 권 다음 행의 시작면 − 1로 계산한 값이다 |
| `82-1` | 가지 면수(끼워 넣은 장). 쪽으로 배정하지 않는다 |
| "공 N" | 공판기록 편철. 권 = "공판기록" |
| `〃` | 위 행 값으로 채우고 `채움`에 열 이름을 남긴다 |
| 순번 `(N)` | 의미 미확인. 버리지 않고 `괄호순번` 표식 |
| 쪽수(증) | 증거분리제출 사건에서만 채워진다. 채워져 있으면 어느 열이 면수 도장과 맞는지 쪽의 `printed_page`와 대조해 정한다 |
| 증인 등 목록(쪽수(공))·압수물총목록 | 별도 표다. 파서는 건너뛴다(`제외표`) |

목록이 여럿이면(병합·추가기소·항소심) 목록마다 `--list-id`를 달리해 돌리고 `--succeeds`로 승계 관계를 적는다. 어느 목록이 어느 권을 커버하는지는 매니페스트 `증거목록[]`에 남는다.

## 2. 증거 단위 배정(`assign`)

매니페스트 `records[].권`이 채워져 있어야 한다. 같은 권 안에서 쪽의 `printed_page`가 어느 순번의 구간에 드는지로 배정한다.

- **확정**: 그 순번의 시작 면수와 일치하는 쪽이 기록에 있다.
- **추정**: 시작 쪽이 없는 순번, 면수 없는 쪽(앞 구간으로 귀속 — `귀속`에 앞뒤 면수, 앞뒤 순번이 다르면 `경계걸침`).
- **미배정**: 목록에 없는 쪽(표지·목록·간지, 추가 편철물).

추정·미배정은 카드에 "변호사 확정 필요"로 옮긴다. 문건 경계와 배정 경계가 어긋나면 카드에 표식을 남긴다.

## 3. 목록 → 기록 대조(`coverage --list-id`)

열람·등사본은 부분 기록이다. `_작업/전수성.json`의 `목록→기록`을 `원천현황.md`의 형사 표로 옮긴다.

| 열 | 내용 |
|---|---|
| 목록ID·순번 | 다중 목록이면 목록별 |
| 증거명칭·작성·성명 | 목록 기재 그대로 |
| (권, 면수 범위) | 파서 결과 |
| 보유 | 전부 / 일부(보유 면수) / 없음 / 판정불가 / 매체·미변환(영상·CCTV 등 — 수동 기재) |
| 카드 | 대응하는 카드 키 |
| 비고 | 면수 없는 쪽의 구간 귀속, 가림 집중, 괄호 순번 |

양면 스캔의 우측 면수(`notes`)도 보유로 센다. 없음·일부가 등사 제외인지 변환 누락인지는 단정하지 않는다. 이 표는 2층 공백·보강 계획(열람·등사 추가 신청 대상)의 입력이다.

## 4. 증거의견(동의 여부)

- 검사 증거목록 사본의 의견·결정란은 통상 비어 있다. 의견이 기재된 목록은 법원이 작성해 공판기록에 편철한다. 입력원은 공판기록의 증거목록 → 변호인 자신의 증거의견서 → 사용자 순이다.
- 부호는 **그 목록의 범례 → 예규** 순으로 해석한다. 피의자신문조서의 연속 부호는 목록에 따라 3연속(성립·임의성·내용)일 수도, 현행 예규의 4연속(적법성·실질성립·임의성·내용)일 수도 있다. "○"은 인정·동의, "×"는 부인·부동의, 특신성 부인은 비고란.
- drafting의 공판의견서 5구분(동의·부동의·내용 부인·동의하되 입증취지 부인·보류)으로 옮길 때는 초안만 채우고 **사용자 확인을 필수로** 한다. 피고인이 여럿이면 피고인별로 받는다.
