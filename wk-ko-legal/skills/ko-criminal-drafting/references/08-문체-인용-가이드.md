# 형사 서면 문체·인용 가이드

공통 기본 문체 규칙은 플러그인 루트의 `shared/기본-문체-규칙.md`(이 skill 디렉토리 기준 `../../shared/기본-문체-규칙.md`) 참조 — 격식체("–습니다/–합니다"), 사실은 단정형, 한자 병기 금지, 항·호·목 "1. → 가. → 1) → 가) → (1)"(HWP 개요번호 표준), 날짜 "2026. 6. 10." 형식, 별칭 규약('이라/라 합니다'), 감정적 표현·추측 표현·의고체·이모지 금지. 판례 검색·인용 정책은 `shared/판례-인용-정책.md` 참조. 여기서는 형사 서면 특유의 규칙만 정리한다.

## 1. 호칭 — 절차 단계별로 엄격히 구분

| 단계·모드 | 호칭 |
|---|---|
| 수사단계 (의견서·영장·적부심) | 피의자 |
| 공판·상소 단계 | 피고인 |
| 고소장·고발장 | 고소인(고발인) / 피고소인(피고발인) |
| 상대 당사자 기관 | 검사 (수사기관 일반은 "수사기관") |
| 피해자 | 피해자 (변호 서면에서 실명 대신 "피해자 ○○○" 첫 정의 후 "피해자") |

- 민사 용어("원고/피고")는 절대 혼입하지 않는다. "피고"와 "피고인"의 혼동이 가장 잦은 오류다.
- 공소사실은 첫 등장 시 "이 사건 공소사실"로 정의하고 이후 통일. 여러 공소사실이면 "제1 공소사실(사기의 점)", "사기의 점"으로 특정.
- 피해자 실명은 낭독·공개 위험을 고려해 "나○○" 식 익명 표기를 쓸 수 있다.
- 법원 호격 "존경하는 재판장님,"은 **낭독용 서면(최후변론·모두진술)에서만** 쓴다. 일반 의견서의 재판부 지칭은 "재판부께서". 수사기관은 "귀청"·"귀서" 대신 정식 기관 명칭으로 적는다.

## 2. 법령·판례 인용

### 법령 — 행위시법 표기
- 현행본과 행위시본이 같으면 통상 표기: 형법 제347조 제1항.
- 행위 후 개정이 있었으면 **구법 표기**: 구 ○○법(2026. 1. 1. 법률 제○○호로 개정되기 전의 것) 제○조. 괄호 정보는 ko-law-api get-asof의 stderr 헤더 출력을 그대로 쓴다.
- 형법 제1조 제2항(경한 신법 우선)이 적용되는 사안이면 신·구법을 대비해 인용하고 적용 법조를 명시한다.

### 판례
검색·인용 정책은 `shared/판례-인용-정책.md` 참조(사전 일괄 검색·판례 패키지, 원문 직접 인용, 추정 인용 금지, 검색 실패 폴백, 표기 형식). 표기 예: "대법원 2024. 5. 8. 선고 2023도12345 판결", 전원합의체 명시, 결정은 "자 ... 결정". **사건부호(도·노·고합·고단·초적 등)를 임의로 만들지 않는다** — lbox에서 확인한 사건번호 그대로 옮긴다. 대표 판례의 법리 설시는 따옴표로 원문 인용(길이 제한 없음), 후속 판례는 사건번호 나열("... 등 참조").

## 3. 증거 인용 표기 (이 skill의 고정 규칙 — 제출 주체별 이원화)

### 검사 제출 증거·수사기록 (증거기록 좌표)
```
(증거순번 3번, 증거기록 152면)
(증거순번 7번, 증거기록 2권 415면)      ← 증거기록이 1권을 넘는 경우
(증거순번 3번 피의자신문조서, 증거기록 152면)   ← 증거명 병기(권장)
```
- **증거순번 + 증거기록 면수**가 기본형. 증거기록이 1권을 넘는 경우 반드시 **권수를 면수 앞에** 표기한다.
- 증거명(조서·진술서 등)을 병기하면 재판부의 확인이 빨라지므로 권장한다.
- 면수가 식별되지 않으면 추측하지 말고 "(증거순번 3번, 증거기록 면수 확인 필요)"로 표시한다.
- 압수물은 압수번호로 특정할 수 있다("○○지검 20○○압제○○○○호 증제○호").

### 피고인(변호인) 제출 증거
```
증 제1호증 ○○계약서          ← 변호인 제출 소명 증거 (갑·을 체계 아님)
참고자료 1 반성문             ← 정상 관계 자료 (반성문·탄원서·진단서·표창장 등)
```
- 변호인이 제출하는 증거는 **"증 제○호증"**, 정상 자료는 **"참고자료 ○"**로 구분한다. 본문 인용과 목록의 번호 일치를 마지막에 대조한다.
- 고소장은 "증 제○호" 표기를 관행상 쓸 수 있다.

### 공판기록·판결문·공소장 좌표
```
(증인 ○○○에 대한 증인신문조서, 공판기록 88면)
(원심판결 5면)
공소사실 제1항의 나. / 범죄일람표 연번 15 내지 24
```
- **공소장·범죄일람표의 번호 체계를 그대로 좌표로 쓴다** — 임의로 다시 매기지 않는다.
- 자기 서면의 재인용은 쪽수까지 특정한다: "(2026. ○. ○.자 변호인의견서 5 내지 8쪽 참조)".

## 4. 형사 서면 특유의 어조·표기

- **공소사실 인용은 그대로, 다툼은 그 아래에서**: 공소사실을 요약·재진술하며 표현을 바꾸지 않는다. 공소사실·원심 판시의 블록 인용에는 **낫표 「 」·『 』**를 쓸 수 있다(민사의 큰따옴표 원칙에 대한 형사 특칙): "이 사건 공소사실의 요지는 「…」는 것입니다."
- **사실 진술과 가정적 주장의 구분**: 예비적 정상 변론은 "가사 이 사건 공소사실이 유죄로 인정된다 하더라도"의 표지로 시작해, 부인 취지가 훼손되지 않게 한다.
- **단정의 방향**: 변호 서면에서 검사 증거의 흠은 단정적으로("...진술은 ...와 모순되어 믿기 어렵습니다"), 피고인에게 유리한 사실 중 증거가 약한 부분은 신중하게 쓴다.
- **양형·정상 서술은 서사형 경어체**: 성장 과정·범행 경위를 시간 순으로 서술하되 감정어는 절제하고 구체적 사실(숫자·기간·기관명)로 정상을 증명한다. 반성 표준 술어는 "진심으로 반성하고 있습니다 / 깊이 뉘우치고 있습니다". 일부 다툼과 반성의 양립은 "다만 ○○ 부분만을 다투고 있을 뿐입니다"로 명시한다. 피해자 관련 서술은 신중 어휘("피해가 조금이나마 회복되기를 바라는 마음으로").
- **반성·선처 문구의 절제**: 정상 변론에서도 "깊이 뉘우치고 있습니다"의 반복보다 구체적 사실(피해 회복 금액, 치료 이수, 재발 방지 조치)이 설득력 있다.
- **고소장의 어조**: 감정적 비난 대신 구성요건 중심의 건조한 기술. 처벌의사는 고소취지에서 분명하게.

## 5. 요청 표현의 강도 단계 (형사 특유)

공통 규칙의 "–하여 주시기 바랍니다"보다 정중도가 한 단계씩 높다(코퍼스 실측).

| 단계 | 표현 | 용처 |
|---|---|---|
| 1 | –하여 주시기 바랍니다 | 절차 요청 일반 |
| 2 | –하여 주시기를 구합니다 / 청합니다 | 참작·판단 요청 |
| 3 | –하여 주시기를 **간곡히** 구합니다(청합니다/요청드립니다) | 선처·파기 등 핵심 요청 |
| 4 | –하여 주시기를 **머리 숙여 구합니다** | 최후변론 결문 최상급 |

- 결문 관용구: "법이 허용하는 최대한의 선처(관대한 처분)", "부디"(결문 강조 부사), "혜량하시어"(절차 신청).
- 결론 주문 정형 — 무죄: "이 부분 공소사실은 범죄사실의 증명이 없는 때에 해당하므로 무죄를 선고하여 주시기 바랍니다." / 예비적 양형: "설령 이와 달리 판단하시더라도, ○○ 점을 참작하여 주시기를 구합니다." / 수사단계: "혐의없음 의견으로 (불송치/불기소)하여 주시기 바랍니다." / 공소기각: "형사소송법 제328조 제1항 ○호에 따라 이 사건 공소를 기각하는 결정을 하여 주시기 바랍니다." / 구체적 형 지정: "부디 피고인에게 벌금형을 내려주시어 …"(형 수위 + 이유 결합).

## 6. 마지막 검수 — 5단계

1. 호칭이 절차 단계에 맞게 통일되었는지(피의자/피고인, 민사 용어 혼입 0건).
2. 증거 인용 표기의 이원화 준수(검사 측 "증거순번 ○번, 증거기록 ○면" / 변호인 측 "증 제○호증"·"참고자료 ○")와 목록 일치.
3. 인용 법령의 시점(행위시법)과 구법 표기의 정확성.
4. 공소사실 인용의 원문 보존(낫표 사용 여부 포함).
5. 가정적 표지("가사 ... 하더라도")의 적절한 사용, 요청 표현의 강도 적정성.
