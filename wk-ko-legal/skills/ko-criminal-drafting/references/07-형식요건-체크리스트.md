# 형사 서면 형식요건 체크리스트

신규 작성 전(게이트)과 초안 완성 후(자체 점검)에 두 번 사용한다. 조문은 모두 국가법령정보 API 실측 기준이며, 의문이 생기면 ko-law-api로 재확인한다.

## A. 작성 전 게이트 (하나라도 걸리면 사용자에게 먼저 알린다)

### A-1. 모드·입장
- [ ] 의뢰인이 피의자·피고인 측인가, 피해자(고소인) 측인가.
- [ ] 변호 서면(절차 신청서 제외)이면 인부(자백/부인/일부 인부)가 확정되었는가 — 미확정이면 작성 전 확인.

### A-2. 기간

| 서면 | 기간 | 근거 |
|---|---|---|
| 항소이유서 | 소송기록접수통지 후 20일 | 형사소송법 제361조의3 제1항 |
| 상고이유서 | 소송기록접수통지 후 20일 | 형사소송법 제379조 제1항 |
| 항소 답변서 | 항소이유서 부본 송달 후 10일 | 제361조의3 제3항 |
| 상고 답변서 | 상고이유서 부본 송달 후 10일(임의적) | 제379조 제4항 |
| 친고죄 고소 | 범인을 알게 된 날부터 6월 | 제230조 |

- [ ] 상소 사건이면 소송기록접수통지일이 자료로 확인되는가. 임박 시 즉시 고지.

### A-3. 상고이유 제한 (형사소송법 제383조)
- [ ] 10년 미만의 형 선고 사건에서 사실오인·양형부당 단독 구성이 아닌가.

### A-4. 소추조건·시효
- [ ] 친고죄·반의사불벌죄 해당 여부와 고소·처벌불원 상태.
- [ ] 공소시효 완성·임박 여부 — 법정형은 행위시법에 따르되 범죄 후 가벼워졌으면 신법 법정형(형법 제1조 제2항, 2008도4376), 시효기간은 범행일에 적용되는 제249조(2007. 12. 21. 전 범죄는 법률 제8730호 부칙 제3조), 적용 배제·특례(제253조의2, 특별법의 공소시효 특례)도 확인. 시효 조문의 적용 판본은 개정 부칙의 경과조치가 정한다 — get-asof 헤더의 "경과조치 확인" 줄대로 `--addenda`로 부칙을 받는다(ko-law-api SKILL.md 5장).

### A-5. 행위시법
- [ ] 범행 일시가 식별되었는가.
- [ ] 적용법조를 행위시 기준으로 확인했는가(ko-law-api get-asof). 법정형 변경이 있으면 형법 제1조 제2항(경한 신법) 검토.
- [ ] 포괄일죄가 법 개정 전후에 걸치면 실행 종료 시의 법(신법)을 적용했는가(97도183). 신설 구성요건이면 시행 후 행위만 대상인가(2015도15669).

## B. 서면별 필수 기재사항

### B-1. 공통
- [ ] 사건 표시(수사기관·법원 사건번호), 죄명, 피의자/피고인 표시
- [ ] 작성 명의(변호인/대리인 변호사)와 제출처(수사기관/법원/재판부)
- [ ] 작성일

### B-2. 변호인의견서 (수사)
- [ ] 구하는 처분(불송치/불기소/기소유예)이 사건 단계에 맞게 명시
- [ ] 호칭 "피의자"

### B-3. 구속 관련 서면
- [ ] 절차 단계와 서면 종류의 일치(영장심사 의견서/적부심 청구서/보석청구서)
- [ ] 적부심·보석은 청구권자 확인, 청구취지의 결정 형식
- [ ] 적부심 청구서 기재사항(형사소송규칙 제102조 — 주거·주민등록번호 등·구속 일자·청구인과의 관계), 보석청구서 기재사항·부본·자력 서면(규칙 제53조 제1항·제2항, 제53조의2 제2항)
- [ ] 구속사유(보석은 제95조 제외사유) 각각에 소명 자료 대응

### B-4. 변론요지서
- [ ] 공소사실에 대한 인부 명시
- [ ] 부인+정상 변론 병행 시 가정적 표지("설령 … 하더라도" — "가사 …"는 허용 변형)
- [ ] 호칭 "피고인"

### B-5. 상소이유서
- [ ] 상소이유의 분류(사실오인/법리오해/양형부당/절차 위반) 항 구분
- [ ] 원심 판결문 인용에 쪽수 표시
- [ ] 상고이유서는 기록과 원심 증거조사에 나타난 사실만 인용(제379조 제2항)
- [ ] 사건부호(노/도)와 법원 표시의 정합

### B-6. 고소장·고발장
- [ ] 고소권자 해당 여부(제223조), 고발은 제234조
- [ ] 죄명·적용법조(ko-law-api 확인, 행위시법 기준)
- [ ] 범죄사실의 특정(일시·장소·방법·결과)과 구성요건 요소 대응
- [ ] 처벌의사 명시
- [ ] 증거 자료 목록("증 제N호증")과 본문 인용 일치

### B-7. 절차 신청서
- [ ] 공판기일변경신청(형사소송규칙 제125조): 변경을 필요로 하는 사유, 그 사유가 계속되리라고 예상되는 기간, 진단서 기타 소명자료 — 서면가이드 구조/절차신청서 §1 골격에는 예상 기간 행이 없으므로 보충한다(법정 기재사항 대조 — `shared/LLM-wiki-연동-정책.md` 4.5).
- [ ] 지정된 기일의 특정, 희망기일(선택)과 첨부서류 표시

## C. 완성 후 공통 점검
- [ ] 호칭 통일 — 수사 "피의자" / 공판·상소 "피고인" / 고소장 "고소인·피고소인". 민사 용어("원고·피고") 혼입 0건.
- [ ] 증거 인용 표기 — 검사 제출 증거는 "(증거순번 ○, 증거기록 ○쪽)"(1권 초과 시 "(증거순번 ○, 증거기록 ○권 ○쪽)"), 피고인(변호인) 제출 증거는 "증 제○호증"·정상 자료 "참고자료 ○". 쪽수 불명은 "확인 필요" 표시.
- [ ] 판례 인용이 모두 판례DB 또는 판례 검색 스킬에서 확인된 것인가(추정 인용 0건 — `shared/판례-인용-정책.md` 3.). 법리 설시는 무부호 전재 + 괄호 출처 형식인가.
- [ ] 양형기준 수치·인자가 로컬 파일 또는 양형위원회 웹사이트에서 확인되었고, 그 판본(시행일)이 적용 시점의 기준(공소제기 시 기준 — 이후 적용대상 제외·가볍게 바뀌었으면 새 기준)과 맞는가(미확인 수치 0건, 로컬 표 셀은 원문과 교차 확인 — SKILL.md 4.6).
- [ ] 합의서·공탁서·반성문 등 정상 자료가 실제 확보된 것만 인용되었는가.
- [ ] 공소사실 인용이 공소장 기재 그대로인가(무단 요약·변형 없음).
- [ ] 증거능력 주장과 증거목록상 동의 여부의 정합.
- [ ] 자료에 없는 사실·수식(선후·동기·산정 기준·전과 유무 등)을 단정하지 않았는가 — 자료에서 추론한 사실은 "확인 필요"를 붙이거나 응답의 "작성 전제로 삼은 가정"에 올렸는가(SKILL.md 11.).
- [ ] 판례 전재문이 판례DB 원문과 글자 단위로 일치하는가 — 접속어는 전재 밖 도입문으로 두고, 원문 중간 생략은 "(중략)"으로 표시(`shared/판례-인용-정책.md` 2.2).
