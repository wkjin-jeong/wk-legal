# 자문의견서 문체·인용 가이드

자문의견서에서 통용되는 격식체와 인용 표기 규칙. 한국 로펌 변호사가 통상 사용하는 문체에 맞춘다.

**공통 기본 문체 규칙은 플러그인 루트의 `shared/기본-문체-규칙.md`(이 skill 디렉토리 기준 `../../shared/기본-문체-규칙.md`) 참조** — 격식체, 사실 단정·평가 완곡, 한자 병기 금지(영문 약칭 병기 규칙 포함), 항·호·목 "1. → 가. → 1) → 가) → (1)"(HWP 개요번호 표준, 최상위 로마자 허용), 날짜 "2024. 5. 8." 형식, 별칭 규약('이라/라 합니다'), 감정적·추측 표현·의고체·이모지 금지, 반복 회피 등. **판례 검색·인용 정책은 `shared/판례-인용-정책.md` 참조**. 여기서는 자문의견서 특유의 규칙만 정리한다.

## 1. 문체의 기본

### 1.1 격식체로 통일 (자문 특유)

자문의견서는 의뢰인 회신용 문서이므로 **"–입니다/–합니다"체**로 통일한다(결론 기본 어미 "~(것으로) 보입니다" — 위키 자문특칙 §1과 같다). 한다체는 판례 원문 전재 문단·큰따옴표 직접 인용 내부·조문 박스 전문에만 쓴다.

- 본문 사실 진술: "...이 거래는 ○○년 ○월 ○일 체결되었습니다."
- 결론 단락: "...따라서 본 건에는 ○○법 제○조가 적용되는 것으로 보입니다."

### 1.2 판단 어조 vs 완곡 어조

자문의견서의 결론은 판단 어조(견해를 명확히 표명하는 어조)로 작성한다. 다만 사실 진술과 결론 진술을 분리해 다음 강도를 사용한다.

| 항목 | 어조 |
|---|---|
| 사실 진술 | 단정형 ("...이 거래는 ...에 체결되었습니다.") |
| 법리 정리 | 단정형 또는 판단 ("판례는 ...라고 해석하고 있습니다.") |
| 사안의 적용 결론 | 판단 — 기본 어미 "~(것으로) 보입니다" ("본 건에서는 ...에 해당하지 않는 것으로 보입니다.") |
| 반대 해석 부기 | 양립 ("다만 ...라는 견해도 가능합니다.") |
| 한계 / 미확정 | 가정 ("...라는 사실이 확인된다는 전제하에 ...") |

어미의 기준(로컬 지식베이스 `서면가이드/문체/자문특칙.md`가 있으면 그쪽이 우선하며, 아래는 그와 정합하는 요약이다):
- **결론·평가의 기본 어미는 "~(것으로) 보입니다"**. 법령 문언이 명확하면 단정형("~에 해당하지 않습니다")으로 올리고, 부정 결론의 완곡은 "~로 보기(는) 어렵습니다".
- **"~로 판단됩니다"·"~라고 생각됩니다"·"~라 할 것입니다"는 쓰지 않는다.** "~다고 사료됩니다"는 보수적 권고 국면 전용("~하여 리스크를 관리함이 타당하다고 사료됩니다").
- **사실 진술에는 추측·완곡 표현을 절대 사용하지 않는다** — 사실 경과는 "~하였습니다" 단정형. 완곡 어미가 판단 가치를 깎는 것은 사실 진술에 잘못 스몄을 때이지, 결론에서의 "보입니다"는 이 사무소의 표준 판단 어조다.

### 1.3 호칭의 일관성

- 의뢰인: 자연인은 "의뢰인", "귀하". 법인은 "귀사", "○○은행" 등 회사 명칭. 한 의견서 안에서 일관성 유지.
- 거래상대방: "거래상대방", "○○회사" 등. "갑"·"을" 같은 계약서식 호칭은 의견서 본문에서는 가독성을 해치므로 첫 등장 시 명칭을 정의한 후 명칭 사용. (예: "주식회사 ○○(이하 '○○'이라 합니다)")
- 변호사·법무법인 자칭: "본 법무법인", "당 법인", "검토자". "저", "우리", "필자" 같은 1인칭 표현은 피한다. 지식베이스가 있으면 위키 자문특칙 §7을 따른다 — 의뢰인은 2인칭 "귀사"(정식 상호는 수신란에만, 본문에서 혼용하지 않는다).
- 감독당국: 첫 등장 시 풀어 쓰고 약칭. (예: "금융위원회(이하 '금융위'라 합니다)").

### 1.4 단락 구성·피해야 할 표현

단락 구성(한 단락 한 주제, 사실 → 평가 순서, 항·호·목 "1. → 가. → 1) → 가) → (1)")과 피해야 할 표현(추측·완곡 남용, 감정적 표현, 이중 부정, 반복, 이모지·과도한 장식)은 `shared/기본-문체-규칙.md` 참조. 자문의견서 특유의 함정:

- **회피적 결론 금지**: "사안에 따라 다릅니다", "추가 검토가 필요합니다"로만 끝나는 결론은 의견서로서의 가치를 떨어뜨린다. 결론을 가르는 변수를 명시한 후 그 변수가 충족되었을 때의 결론을 분명히 제시한다.

## 2. 한자 병기·영문 약칭

한자 병기 금지의 일반 원칙은 `shared/기본-문체-규칙.md` 참조. 은행·금융 자문에서 자주 쓰는 영문 약칭은 첫 등장 시 풀어 쓰고 괄호 안에 영문 원어를 병기한 뒤 이후 약칭 또는 한글로 통일한다.
- "고객확인의무(Customer Due Diligence, CDD)" → 이후 "고객확인의무" 또는 "CDD"로.

## 3. 인용 표기

### 3.1 법령 인용

의견서 본문의 법령 인용은 이 절을 따른다 — 무괄호 "은행법 제35조", 약칭 정의 "(이하 '자본시장법'이라 합니다)"(위키 공통 §5·§8, 자문특칙 §0 준용). 법령명에는 「」를 붙이지 않는다 — ko-law-api의 인용 형식 안내보다 이 가이드가 우선한다(조문 박스·원문 전재 안의 「」·괄호 한자는 원문 그대로).

기본 형식:

```
은행법 제35조
은행법 제35조 제1항 단서
민법 제2조 제1항(신의성실)
주택임대차보호법 제3조의2 제1항
자본시장과 금융투자업에 관한 법률 제174조 제1항
```

- 법령명을 정확히 — "민사소송법" / "민법" / "상법" / "은행법" / "자본시장법"(또는 정식 명칭). 약칭 사용 시 첫 등장에서 풀어 쓰고 약칭 정의.
  - "자본시장과 금융투자업에 관한 법률(이하 '자본시장법'이라 합니다) 제174조"
- 조·항·호·목·단서를 정확히 인용.
- 본문에서 처음 인용 시 법령명을 풀어 쓰고, 같은 의견서 내 반복 등장하면 "같은 법", "위 법" 등으로 약칭 가능.

### 3.2 시행령·시행규칙·감독규정 인용

```
은행법 시행령 제○조
은행업감독규정 제○조 (금융위원회 고시 제○○-○호)
```

- 행정규칙(고시)은 발신부서·문서번호를 첫 등장 시 명시.
- 시행 일자가 결론에 영향을 주면 본문에 시행일자도 표시.
  - "(○○○○. ○. ○. 시행 외국환거래법 제○조)" — 시행일은 ko-law-api로 확인한 값만 쓴다.

### 3.3 판례 인용

판례 조사·인용의 상세 규칙(판례DB 우선 사전 조사·판례 패키지, 원문 전재 형식, 추정 인용 금지, 검색 실패 폴백, 표기 형식)은 **`shared/판례-인용-정책.md` 참조**. 자문 요약:

- 판례는 **판례DB(원격 MCP·로컬)를 우선 조사해 확인**한 사건번호·선고일자·판결 종류만 인용한다(추정·기억에 의한 인용 절대 금지, 브라우저 검색 스킬은 `shared/판례-인용-정책.md` 1.1의 경우에만). 판례DB 원문은 원본 대조 없이 인용한다.
- 핵심 판례의 법리 설시는 **따옴표 없이 한다체 원문 그대로 전재하고 문미 괄호 출처로 닫는다**(자문특칙 §4가 준용하는 공통 §4 — 강조가 필요할 때만 큰따옴표 직접 인용). 후속 판례는 같은 괄호에 병기("… 등 참조"). 원문 전재에 제약이 없는 근거·표기 규칙은 shared 정책 참조.
- 표기 예: "[판시 원문 한다체 전재](대법원 ○○○○. ○. ○. 선고 ○○○○다○○○○○ 판결 참조)." / 직접 인용형 "대법원은 \"[원문]\"라고 판시한 바 있습니다(대법원 … 판결)." / 결정 "대법원 ○○○○. ○. ○.자 ○○○○마○○○ 결정".

### 3.4 유권해석·비조치의견서·법령해석 회신 인용

```
금융위원회 ○○○○. ○. ○.자 비조치의견서 (문서번호: ○○○○-○○○)
금융감독원 ○○국 ○○○○. ○. ○.자 유권해석 (○○○-○○-○○)
금융위원회 ○○과 ○○○○. ○. ○.자 법령해석 회신 (bigcase 일련번호: ○○○○○○)
```

- 기관·부서(원문의 '소관부처'·'소관부서'·'회신부서'), 일자, 문서 종류, 번호를 원문 머리에서 옮긴다 — 원문에 과 이름만 있으면 `[발신기관 확인 필요]`.
- 일자는 회신일이다. 금융규제·법령해석포털 목록의 '등록일'은 질의 등록일이므로 쓰지 않는다(예: 일련번호 220200은 등록일 2022. 9. 6., 회신일 2023. 8. 10.).
- 문서 종류는 원문 표제대로 쓴다('법령해석 회신'·'비조치의견서 회신' 등). '유권해석'은 원문 표제가 없을 때만 쓴다.
- 원문의 문서번호만 '문서번호'라고 쓴다. bigcase 카드·제목의 번호는 사이트 일련번호(금융규제·법령해석포털 목록의 '일련번호'와 같다)이므로 '(bigcase 일련번호: …)'로만 병기하고, 원문에 문서번호가 없으면 문서번호를 적지 않는다(bigcase-case-search `references/extraction.md` 4장). 번호가 전혀 없으면 기관·부서·일자·표제로만 특정한다.
- 인용의 한계를 함께 표시한다.
  - 비조치의견서: "단, 비조치의견서는 발신자에 대한 행정처분 면책 의미만을 가지며 일반적 법적 구속력은 제한적입니다."
  - 법령해석 회신·유권해석: "질의에 대한 감독당국의 해석으로서 일반적 법적 구속력은 제한적입니다."
- 결정례(금융분쟁조정위원회 조정결정·공정거래위원회 의결·국민권익위원회 의결 등)의 인용 형식과 구속력 한계는 3.8을 따른다.
- 유권해석·비조치의견서·결정례는 bigcase를 우선 검색하고(`shared/판례-인용-정책.md` 1.1 특성 라우팅 — 법제처 해석례는 ko-law-api `expc`. 유권해석은 bigcase 유권해석 탭 `https://bigcase.ai/search/regulation-interpretation?q={검색어}&page=1`, 절차는 bigcase-case-search `references/extraction.md` 1-4·4장. 없으면 금융규제·법령해석포털 — `references/02-금융법령-체크리스트.md` 2.3), 찾지 못하면 본문에는 조문·회신일(결정례는 의결일)·적용범위만 정확히 기재하고 사용자에게 원문 확인을 요청.

### 3.5 약관·내규 인용

자문의뢰 사안에 적용되는 약관·내규는 본문에 정확히 인용.

```
○○은행 인터넷뱅킹 이용약관(○○○○. ○. ○. 시행) 제○조 제○항
○○은행 비대면 대출 업무처리내규 제○조
```

- 약관·내규의 시행일자를 표시.
- 첨부물로 약관 사본을 함께 제출하는 경우 "(첨부 1)" 형태로 본문에 표시하고 의견서 말미에 첨부물 목록 정리. 지식베이스가 있으면 본문에서 "(첨부자료 N '문서명')"으로 참조한다(위키 자문특칙 §6, 6장).
- 약관 조항의 핵심 문구는 따옴표로 인용 가능.

### 3.6 표준약관·국제계약서 인용

```
은행여신거래기본약관 제○조 (○○○○. ○. ○. 시행)
ISDA 2002 Master Agreement Section ○
```

- 영문 표준계약서는 영문 원어로 인용. 필요 시 한글 번역을 괄호로.

### 3.7 영문 자료 인용

```
"제목" (Cite original English title) (Author, Year)
```

- 영문 자료의 직접 인용은 신중히. 한국 자문 의견서의 표준은 한글이므로 영문 자료는 부수적 참고로.

### 3.8 재결례·결정례(의결·결정) 인용

**재결**

```
중앙행정심판위원회 ○○○○. ○. ○.자 ○○○○-○○○○ 재결
○○도행정심판위원회 ○○○○. ○. ○.자 ○○○○○○행심○○○ 재결
```
- 재결 기관(행정심판위원회)은 재결서 원문(PDF 본문)의 첫머리(예: `[○○행정심판위원회사건 {사건번호}, {재결일}, {결과}]`)나 끝의 위원회 표시에서 확인해 적는다. bigcase 카드·제목(h1)의 기관명은 사이트의 제공 기관 분류라 재결 기관과 다를 수 있으므로 옮기지 않는다. 카드 발췌·재결요지에 붙은 대괄호 머리(예: `[국민권익위원회 2014-05850, 2014. 12. 2.]`)도 사이트가 붙인 것이므로 원문 머리로 보지 않는다.
- 재결은 행정심판위원회가 한다. 국민권익위원회는 중앙행정심판위원회를 두는 기관일 뿐이므로 기관 표시가 "국민권익위원회"뿐이면 재결 기관으로 쓰지 않는다. 소관 위원회는 처분청에 따라 행정심판법 제6조가 정한다 — 제1항 각 호의 행정청(감사원·국가정보원장 등)은 그 행정청에 두는 위원회, 그 밖의 국가행정기관의 장과 시·도지사·시·도의회 등은 국민권익위원회에 두는 중앙행정심판위원회(제2항), 시·도 소속 행정청과 시·군·자치구의 장·의회 등은 시·도지사 소속 위원회(제3항), 대통령령으로 정하는 특별지방행정기관의 장은 직근 상급행정기관에 두는 위원회(제4항).
- 원문에 위원회명이 없으면 사건번호 체계(경기행심·서행심 등)·피청구인·위 제6조로 추정하지 않는다. 인용 자리에 `[재결 기관 확인 필요]`를 달고 미해결 표식으로 보고한다(`shared/판례-인용-정책.md` 4.).
- 재결례도 원문(주문·이유)을 읽어 확인한 것만 인용한다(`shared/판례-인용-정책.md` 3. 준용). 다른 사건의 재결은 이 사건을 구속하지 않으므로 법리 근거는 판례를 앞세우고, 재결례는 같은 취지의 보충 자료로 쓴다.

**결정례(의결·결정)**

```
국민권익위원회 ○○○○. ○. ○.자 제○○○○-○소위○-○○호 의결
소청심사위원회 ○○○○. ○. ○.자 ○○○○-○○○ 결정
금융분쟁조정위원회 ○○○○. ○. ○.자 조정결정 (원문의 결정 번호)
공정거래위원회 ○○○○. ○. ○.자 의결 제○○○○-○○○호
```
- 기관·일자·번호는 재결과 같이 원문 머리에서 확인한다(bigcase 카드·제목의 번호는 사이트 일련번호일 수 있다). 의결의 종류(시정권고·의견표명·조정·제도개선 권고)는 원문 주문에서 확인해 적는다.
- 자료 성격(구속력)을 본문에 밝히고, 구속력 없는 자료를 구속력 있는 판단처럼 쓰지 않는다.

| 자료 | 구속력 | 근거 |
|---|---|---|
| 행정심판 인용재결 | 그 사건의 피청구인과 관계 행정청을 기속 — 다른 사건에서는 참고 자료 | 행정심판법 제49조 제1항 |
| 국민권익위원회 고충민원 시정권고·의견표명 | 기속하지 않음 — 관계 행정기관등의 장은 존중하고 30일 이내 처리결과를 통보하며, 권고를 이행하지 않으면 그 이유를 문서로 통보 | 부패방지 및 국민권익위원회의 설치와 운영에 관한 법률 제46조, 제50조 제1항·제2항 |
| 국민권익위원회 조정 | 당사자가 조정서에 기명날인하거나 서명하고 위원회가 확인하면 성립, 민법상 화해와 같은 효력 | 같은 법 제45조 제2항·제3항 |
| 소청심사위원회 결정 | 그 사건의 처분 행정청을 기속 — 다른 사건에서는 참고 자료 | 국가공무원법 제15조 |
| 조세심판원 결정 | 그 사건의 관계 행정청을 기속 — 다른 사건에서는 참고 자료 | 국세기본법 제80조 제1항 |
| 금융분쟁조정위원회 조정결정 | 양 당사자가 조정안을 수락한 경우에만 재판상 화해와 같은 효력 — 다른 사건을 구속하지 않음 | 금융소비자 보호에 관한 법률 제39조 |
| 공정거래위원회 약관 시정 의결 | 해당 사업자에 대한 시정권고·시정명령 — 약관 조항의 사법상 효력은 법원이 따로 판단 | 약관의 규제에 관한 법률 제17조의2 |

- 금융소비자 보호에 관한 법률 시행(2021. 3. 25.) 전의 조정결정은 구 금융위원회의 설치 등에 관한 법률(2020. 3. 24. 법률 제17112호로 개정되기 전의 것) 제55조를 근거로 쓴다 — 조문은 조정결정일 기준 get-asof로 확인한다.
- 은행 약관에 대해 공정거래위원회가 금융위원회에 시정 조치를 요청하거나(은행법 제52조 제4항) 금융감독원에 시정 조치를 권고한 경우(약관의 규제에 관한 법률 제18조 제2항)는 사업자에 대한 처분이 아니다 — 원문의 근거 조문대로 적고 같은 사법상 효력 한계를 붙인다.

- 법제처 법령해석례는 ko-law-api의 법령해석례 인용 형식(byl_expc.md)을 따른다.

## 4. 호칭 기본

### 4.1 의뢰인 호칭

- 자연인: "의뢰인 ○○○ 귀하".
- 법인: "주식회사 ○○ 귀사" 또는 "○○은행 귀사". 첫 등장 후 약칭 가능. 지식베이스가 있으면 위키 자문특칙 §7을 따른다 — 본문은 2인칭 "귀사"로 부르고 정식 상호는 수신란에만 적는다(혼용하지 않는다).
- 의뢰인이 의견서 발신 대상이면 "수신: ○○ 귀하"로 표제 표기.

### 4.2 거래상대방·관련 당사자 호칭

- 첫 등장 시 풀어 쓰고 약칭 정의.
  - "주식회사 ○○(이하 '○○'이라 합니다)"
- 다수 당사자가 있을 때는 "○○ 측", "○○ 그룹" 등으로 묶을 수 있다.

### 4.3 감독당국·법원 호칭

- 금융위원회 → "금융위원회" 또는 "금융위" (첫 등장 후).
- 금융감독원 → "금융감독원" 또는 "금감원".
- 한국은행 → "한국은행".
- 법원: "대법원", "○○고등법원", "○○지방법원" 그대로.

## 5. 표·도식의 사용

자문의견서는 본문 중심. 표는 다음의 경우에만 활용한다.

- **거래구조도**: 다수 당사자 거래의 자금·물건 흐름을 한눈에 보이고자 할 때.
- **법령 비교**: 개정 전후 법령의 차이, 다른 분야 법령의 비교.
- **시점별 효력 비교**: 시점별로 결론이 다른 경우.
- **리스크 평가**: 리스크 카테고리별 발생 가능성·영향도.
- **권고사항**: 후속 액션 항목과 우선순위.

표 안의 내용도 격식체로 작성한다.

## 6. 첨부물 표기

지식베이스가 있으면 본문에서 "(첨부자료 N '문서명')"으로 참조한다(위키 자문특칙 §6). 아래 말미 첨부물 목록은 지식베이스가 없을 때의 형식이다.

자문의견서에 첨부물이 있을 때는 의견서 말미에 첨부물 목록을 정리한다.

```
## VI. 첨부

1. 첨부 1: 검토 대상 약관(○○은행 인터넷뱅킹 이용약관, ○○○○. ○. ○. 시행).
2. 첨부 2: 의뢰인 제공 사실관계 메모(○○○○. ○. ○.자).
3. 첨부 3: 인용 판례 목록.
```

본문에서 첨부물을 인용할 때는 "(첨부 1 약관 제○조)"식으로 표기.

## 7. 분량·구두점·번호 매기기

### 7.1 분량 가이드

- 한 문장은 한 호흡(60~80자) 이내가 가독성에 유리.
- 한 단락은 1~2문장이 기본이고 3문장 이상 뭉텅이 단락은 쓰지 않는다(`../../shared/기본-문체-규칙.md` 7.).

### 7.2 구두점

- 마침표(.), 쉼표(,), 콜론(:), 세미콜론(;)을 활용.
- 마침표는 모든 문장 끝에. 항·호 표지 다음에는 마침표. (예: "1.", "가.")
- 쉼표는 의미 단위 구분에 한정. 남용 금지.
- 따옴표는 ""(큰따옴표)와 ''(작은따옴표) 두 종류. 큰따옴표가 직접 인용·강조용, 작은따옴표가 인용 안의 인용 또는 강조 표시용.

### 7.3 번호 매기기

자문의견서 본문 항·호·목 분류:

```
I.   (또는 1.) — 최상위 (예: 사안의 개요, 검토 의견)
1.    — 중상위 (예: 질의 1)
가.   — 중간 (예: 쟁점)
1)    — 하위
가)   — 그 아래
(1)   — 최하위
```

대문자 로마자는 검토 의견의 최상위 분류(I·II·III·IV·V·VI)에 사용 가능. 그 이하는 "1. → 가. → 1) → 가) → (1)"(HWP 개요번호 표준) 한 가지로 통일. ①②③은 헤딩이 아니라 문단 내 열거 전용.

## 8. 인용 누락·오류 방지

### 8.1 인용 검증 체크리스트

- [ ] 모든 판례 인용이 판례DB 또는 판례 검색 스킬로 확인된 사건번호인가? (추정 인용 0건)
- [ ] 전재·직접 인용한 원문이 판례DB(또는 검색 스킬)에서 읽은 원문과 정확히 일치하는가?
- [ ] 사건번호의 법원·연도·종류 표기가 정확한가?
- [ ] 전원합의체 표기가 누락되지 않았는가?
- [ ] 법령 조·항·호 인용이 정확한가?
- [ ] 시행일자·개정 이력이 사안의 시점에 부합하는가?
- [ ] 약관·내규의 시행일자가 표기되어 있는가?
- [ ] 유권해석·비조치의견서·결정례의 기관·부서·일자(회신일·의결일)·원문 표제·번호(문서번호가 없으면 bigcase 일련번호로 병기)가 원문과 일치하고, 인용 한계 문구가 붙었는가?

### 8.2 자주 발생하는 인용 오류

- **사건번호 자릿수**: "2023다12345"는 올바르나 "2023다1234"·"2023다123456"은 서로 다른 판례. 자릿수 점검.
- **선고일자 vs 결정일자**: 결정은 "선고" 대신 날짜에 붙인 "자"를 사용("2015. 6. 11.자").
- **법령명 약칭**: "자본시장법" 등 약칭은 첫 등장 후. 첫 등장에서 풀어 쓰고 약칭 정의.
- **조·항 혼동**: "제○조 제○항"의 "제"를 빠뜨리는 경우. 법령 인용은 정식 표기.
- **상사·민사 시효 혼동**: "10년의 상사시효"·"5년의 민사시효" 등은 잘못. 상사 5년, 민사 10년.

## 9. 영문 자문의견서가 필요한 경우

의뢰인이 외국 의뢰인이거나 영문 의견서가 필요한 경우, 본 skill은 한글 의견서를 작성하고 영문 번역은 별도로 처리한다(번역 시 법률 용어의 표준 영문 표기 — Black's Law Dictionary, ICC Model Forms 등 참조).

영문 자문의견서가 직접 필요한 경우(closing opinion to lender 등)는 본 skill의 범위가 아니므로 사용자에게 별도 양식 요청.
