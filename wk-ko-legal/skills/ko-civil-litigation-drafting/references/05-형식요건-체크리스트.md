# 형식요건 체크리스트

서면 작성·검토 마지막 단계에서 처음부터 끝까지 따라가며 점검한다. 한 번 봐서 잘 안 잡히는 항목이 많으니, 의심나면 두 번 본다.

## 공통 — 모든 서면에 적용

### 표제와 사건 표시
- [ ] 서면 종류(소장·답변서·준비서면)를 정확히 표제로 적었는가.
- [ ] 답변서·준비서면이라면 사건번호("20○○가합○○○○" 또는 "20○○가단○○○○")를 정확히 표시했는가.
- [ ] 사건명("○○○ 청구의 소")이 청구의 법적 성격에 부합하는가.
- [ ] 준비서면이 두 번째 이상이라면 차수("(2)", "(3)" 등) 또는 변호사 통상 관행에 따른 차수 표시.

### 당사자 표시
- [ ] 자연인의 성명·주소가 정확한가(주민등록상). 송달장소가 다르면 별도 명시.
- [ ] 법인의 명칭이 등기부 그대로인가("주식회사" 위치, "(주)" 약칭 사용 여부 일관성).
- [ ] 법인 대표자 표시(대표이사 ○○○).
- [ ] 다수 당사자(원고1·원고2 / 피고1·피고2)의 호칭이 본문에서 일관되게 유지되는가.
- [ ] 미성년자·피한정후견인 등의 법정대리인 표시.
- [ ] 당사자·소송대리인 표시 — 이름·주소·연락처(전화·팩스·전자우편 등)(민사소송규칙 제2조 제1항 제2호). 앞서 낸 서면과 주소·연락처가 같으면 이후 서면은 생략 가능(같은 조 제2항) — 그 사건에서 처음 내는 서면(소장·답변서, 별도 사건번호가 붙는 신청사건의 신청서 등)은 생략 불가.

### 본문 일관성
- [ ] 호칭 — "원고", "피고"로 통일(피고인·청구인·신청인 등 다른 절차 용어 혼입 여부).
- [ ] 문체 — 격식체("–습니다/–입니다/–합니다"체) 통일. 구어체·반말 혼입 금지.
- [ ] 항목 표제 — "1. → 가. → 1) → 가) → (1)"((1) 아래는 "(가)") 체계로 일관(①②③은 문단 내 열거에 쓰고, ㉠·㈎ 등 다른 체계는 섞지 않는다).
- [ ] 별칭 정의 — "(이하 '○○'이라 합니다)" 어미가 받침 유무에 맞는가('이라/라'). 정의한 별칭·"이 사건 ○○" 명명을 끝까지 일관 사용.
- [ ] 인명·지명·법인명이 처음 등장한 표기를 일관되게 유지.
- [ ] 날짜 표기 — 연·월·일을 모두 적을 때는 "2024. 5. 8.", 일부만 적을 때는 연·월 "2024. 5."(시기 불명은 "2024. 5.경"), 연도만 "2024년"(`shared/기본-문체-규칙.md` 5.). 한 서면 안에서 일관.
- [ ] 금액 표기 — 정밀 맥락(청구취지·계산 내역)은 전자릿수형 "100,000,000원", 서술문은 억·만 혼합형 허용, 같은 맥락은 한 서면 안에서 일관. 한글 병기 없음.

### 증거 인용
- [ ] 본문에서 인용한 증거가 증명방법 목록에 있는가 — 준비서면은 이번에 새로 내는 증거만 목록에 적으므로(`03-준비서면-template.md` 증명방법 항) 기제출 증거는 호증번호가 앞선 서면의 목록과 일치하는지로 점검.
- [ ] 증명방법 목록의 모든 증거가 본문에서 인용되는가(목록만 있고 본문 무인용은 분량 낭비).
- [ ] 증거번호 형식 — 원고 "갑 제○호증", 피고 "을 제○호증". 가지번호("의 1, 의 2") 사용 시 일관.
- [ ] 호증명이 증거의 성격을 정확히 표현하는가.

### 작성일과 법원
- [ ] 작성일이 사건 진행 시점에 부합하는가(미래 일자 또는 현저한 과거 일자가 아닌지).
- [ ] 변호사 또는 본인 서명란.
- [ ] 법원 표시 — 답변서·준비서면이라면 재판부까지("○○지방법원 제○민사부(○) 귀중").
- [ ] 첨부서류 — 제목과 "(변호사 확인 후 기재 — 민사소송규칙 제2조 제1항 제3호)" 한 줄만 두었는가(목록을 지어내지 않는다).

> **첨부서류의 내용 점검은 본 체크리스트 범위 밖이다.** 본 skill의 출력은 첨부서류 자리표시 한 줄까지이고, 인지·송달료·부본 통수·법인등기부등본 등 사무적 첨부서류는 변호사가 별도로 관리한다.

## 소장 전용 점검

### 청구취지의 특정성
- [ ] **금전 청구**: 원금 + 기산일 + 종기("다 갚는 날까지") + 이율 + "비율로 계산한 돈".
  - [ ] 변제기까지의 약정이자와 변제기 이후의 지연손해금을 구분해야 한다면 단계별 표시.
  - [ ] 이율이 약정이율인지 법정이율(연 5% 민사 / 연 6% 상사)인지 또는 소송촉진법 이율(연 12%)인지 명시.
- [ ] **부동산 인도/명도**: 부동산을 등기부 그대로 특정(소재지·지번·지목·면적, 건물은 동·호수·구조까지).
- [ ] **등기 청구**: 등기 표시(부동산 + 등기소 + 접수일 + 접수번호 + 등기 종류 + "이전등기/말소등기절차를 이행하라").
- [ ] **확인의 소**: 확인 대상이 명확히 특정되어 있는가.
- [ ] **소송비용 부담**: "소송비용은 피고가 부담한다."
- [ ] **가집행 선고**: 적합한 청구인지(원칙적으로 재산권 이행청구만 — 의사진술·등기절차 이행·확인·형성·비재산권은 부적합, 형성의 소와 병합한 이행청구는 사용자 확인. 민사소송법 제213조 제1항, 민사집행법 제263조 제1항).
- [ ] 종결문 — "라는 판결을 구합니다."

### 청구원인의 정합성
- [ ] 청구원인이 청구취지의 모든 요소(원금·이자·기산일 등)를 지탱하는가.
- [ ] 요건사실이 빠짐없이 진술되었는가(쟁점별 논증구조 reference 참고).
- [ ] 청구의 법적 근거(조문)가 결론 부분에서 분명한가.

### 관할
- [ ] 토지관할 — 피고 보통재판적, 의무이행지(지참채무·추심채무), 부동산 소재지 등.
- [ ] 사물관할 — 소가 5억 원 초과 사건과 민사소송 등 인지법 제2조 제4항 사건(소가를 계산할 수 없는 재산권상 소·비재산권 소)은 합의부(민사 및 가사소송의 사물관할에 관한 규칙 제2조 본문. 5억 원 기준은 2022. 3. 1. 시행 — 그 전에 접수된 사건은 종전 2억 원 기준, 부칙(2022. 1. 28.) 제2조). 다만 ① 수표금·약속어음금 청구, ② 같은 조 제2호의 금융기관(은행·농협·수협·신협·신용보증기금·새마을금고·상호저축은행·보험회사·신용카드회사 등)이 원고인 대여금·구상금·보증금 청구, ③ 자동차손해배상 보장법에서 정한 자동차·원동기장치자전거·철도차량의 운행 및 근로자의 업무상재해로 인한 손해배상 청구와 그 채무부존재확인, ④ 단독판사가 심판할 것으로 합의부가 결정한 사건은 소가와 관계없이 단독(같은 조 단서). 반대로 합의부에서 심판할 것으로 합의부가 결정한 사건은 소가와 관계없이 합의부(법원조직법 제32조 제1항 제1호). 제소 시점의 규칙은 ko-law-api(get-asof)로 확인.
- [ ] 합의관할·전속관할 — 약정 또는 법령상 전속관할 검토.

### 인지·송달료
범위 밖이다(변호사가 별도 산정·관리 — 본문에 적지 않는다). 후기(모드 B에서는 변경 사항 논평)에서 변호사 확인 사항으로 권고한다(SKILL.md 10.).

## 답변서 전용 점검

- [ ] 제출기한 — 소장 부본 송달일부터 30일(민사소송법 제256조 제1항) 안인가. 기간 안에 다투는 답변서를 내지 않으면 무변론판결 대상(제257조 제1항). 송달일이 불명이면 후기에서 확인 요청.
- [ ] 청구취지에 대한 답변이 명확한가("기각" / "각하" / 일부 답변).
- [ ] 청구원인 모든 단락에 대해 인정/부인/부지 입장이 표시되었는가(누락은 자백 간주).
- [ ] 부인 사실에 대해 적극적 부인 사유를 덧붙였는가.
- [ ] 항변과 부인을 혼동하지 않았는가.
- [ ] 시효 항변 — 기산점·시효기간·만료시점이 모두 명확한가.
- [ ] 상계 항변 — 자동채권의 특정과 상계 의사표시 시점이 명확한가.
- [ ] 동시이행 항변 — 반대급부의 내용이 정확히 특정되어 있는가.
- [ ] 반소·소송고지 검토 — 단순 답변을 넘어 별도 소송행위가 필요한지(본문 외 별지 신청서로 처리하되 사용자에게 안내).

## 준비서면 전용 점검

- [ ] 제출시기 — 새로운 공격방어방법이 있으면 변론(준비)기일 7일 전까지 상대방에게 송달될 수 있도록 제출하는 일정인가(민사소송규칙 제69조의3). 기일을 모르면 후기에서 확인 요청.
- [ ] 분량 — 30쪽 이내이고(민사소송규칙 제69조의4 제1항 — 같은 규칙 제70조 제4항의 합의가 있으면 예외), 소장·답변서·앞선 준비서면과 중복·유사한 내용을 불필요하게 반복하지 않았는가(같은 조 제3항).
- [ ] 작성자(원고/피고) 표시가 첫 줄(모두문)에 분명한가 — 모두문은 통상 "위 사건에 관하여 …의 소송대리인은 다음과 같이 변론을 준비합니다."이고, 그 아래에 「다 음」을 둔다.
- [ ] 반박 대상 서면을 날짜로 특정했는가("피고의 2026. ○. ○.자 준비서면에 대하여").
- [ ] 직전 서면(소장·답변서·이전 준비서면)의 호증번호 다음부터 새 호증번호를 매겼는가(중복·건너뜀 없음).
- [ ] 상대방 주장의 요지를 정확히 인용했는가(왜곡·축소 금지).
- [ ] 각 쟁점 항목이 「관련 법리 → 이 사건의 경우 → 소결」(소결은 말미 문단 흡수 가능)을 갖추었는가 — 사실 반박형은 법리 생략 가능, 상대 주장의 요지는 앞의 대항목(예: "1. 원고 주장의 요지")이나 쟁점 항목 머리에 두었는가(SKILL.md 4.3).
- [ ] 법리 단락의 판례가 판례 패키지(판례DB 우선 — `shared/판례-인용-정책.md` 1.1)에서 왔고, 원문 그대로 옮겼으며(따옴표 없는 전재 + 괄호 출처가 기본, 큰따옴표 직접 인용도 가능 — 같은 정책 2.2), 핵심 쟁점에 대표 1건 + 후속 1~2건인가.
- [ ] 핵심 쟁점에 분량을 집중하고, 부수 주장은 짧게 처리했는가.
- [ ] 청구의 변경(교환적·추가적)에 해당하는 사항이 있다면 별도 청구취지 변경 신청서를 안내했는가.
- [ ] 결론 단락에서 이 서면이 향하는 결과를 명시했는가.

## 상소 서면 전용 점검

민사 항소이유서·상고이유서·상고이유 답변서(SKILL.md 4.2)에 적용한다. 기간 조문은 제출 시점 기준으로 ko-law-api로 확인하고, 통지·송달일이 불명이면 후기에서 확인을 요청한다.

- [ ] **항소이유서** — 항소장에 항소이유를 적지 않았으면 항소기록 접수 통지(민사소송법 제400조 제3항)를 받은 날부터 40일 이내(제402조의2 제1항 — 신청하면 1회 1개월 연장, 같은 조 제2항). 어기면 항소각하 결정(제402조의3 제1항 — 직권조사 사유가 있거나 항소장에 항소이유가 있으면 예외). 제402조의2·제402조의3은 그 개정법 시행일(2025. 3. 1.) 후 최초로 항소장이 제출된 사건부터 적용된다(민사소송법 부칙<법률 제20003호, 2024. 1. 16.> 제1조·제2조).
- [ ] **상고이유서** — 상고장에 상고이유를 적지 않았으면 소송기록 접수 통지(제426조)를 받은 날부터 20일 이내(제427조 — 어기면 변론 없이 상고기각, 제429조 — 직권조사 사유가 있으면 예외, 같은 조 단서). 상고이유를 판결에 영향을 미친 헌법·법률·명령 또는 규칙의 위반으로 구성했는가(제423조 — 심리불속행 사유는 상고심절차에 관한 특례법 제4조).
- [ ] **상고이유 답변서** — 상고이유서를 송달받은 날부터 10일 이내에 낼 수 있다(제428조 제2항).

## 신청 서면 전용 점검

보전·집행·담보·절차 신청서(SKILL.md 4.6)에 적용한다. 신청서의 법정 기재사항은 이 절이 1차 기준이다. 법령·규칙이 기재사항을 정한 서면은 근거 조문을 ko-law-api로 get해 요소별로 대조하고 빠진 요소를 채운다 — 아래에 그 서면의 항목이 없어도 생략하지 않는다(지식베이스가 있어도 같다 — `shared/LLM-wiki-연동-정책.md` 4.3·4.5).

- [ ] **보전처분 공통** — 신청의 취지와 이유, 사실상의 주장을 소명하기 위한 증거방법(민사집행규칙 제203조 제2항).
- [ ] **가압류** — 청구채권의 표시(일정 금액이 아니면 금전 환산액)와 가압류의 이유가 될 사실의 표시(민사집행법 제279조 제1항), 청구채권·가압류 이유의 소명(같은 조 제2항).
- [ ] **가처분** — 가압류 절차 준용(민사집행법 제301조). 다툼의 대상에 관한 가처분(제300조 제1항)과 임시의 지위를 정하기 위한 가처분(같은 조 제2항)의 요건을 구분해 소명했는가.
- [ ] **채권압류·추심** — 압류할 채권의 종류와 액수(민사집행법 제225조), 채권자·채무자·제3채무자와 그 대리인의 표시, 집행권원의 표시, 일부만 신청하면 그 범위(민사집행규칙 제159조 제1항). 신청취지에 제3채무자에 대한 지급금지와 **채무자에 대한 채권의 처분·영수 금지**를 모두 넣었는가(민사집행법 제227조 제1항). 추심명령·전부명령은 제229조.
- [ ] **문서제출신청** — 문서의 표시, 문서의 취지, 문서를 가진 사람, 증명할 사실, **문서를 제출하여야 하는 의무의 원인**(민사소송법 제344조 제1항 각 호·제2항 중 해당 근거) 5개 항목(같은 법 제345조 제1호~제5호), 서면 신청(민사소송규칙 제110조 제1항).
- [ ] **기일변경** — 변경이 필요한 사유를 밝히고 소명자료를 붙였는가(민사소송규칙 제40조).
- [ ] **감정** — 감정을 구하는 사항을 적은 서면(민사소송규칙 제101조 제1항).
- [ ] **그 밖의 유형**(문서송부촉탁·변론재개·담보취소·권리행사최고 등) — 근거 조문을 ko-law-api로 get해 법정 기재사항과 요소별로 대조한다.
- [ ] **증거 부호** — 별도 사건번호가 부여되는 신청사건(보전·집행·담보)은 "소갑 제○호증", 본안 사건 안의 절차 신청은 그 사건의 갑·을 호증(`references/06-문체-인용-가이드.md` 2장).

## 자주 빠뜨리는 사항 — 마지막 한 번 더 점검

- [ ] **법인 당사자 표시** — 명칭·대표자·본점 소재지가 등기사항증명서와 일치하는가(증명서 첨부는 범위 밖).
- [ ] **인용한 판례·법령 번호의 정확성** — 사건번호·선고일자·판결 종류(전합·일반)가 정확한가. 판례DB·검색 스킬로 확인한 것만 남기고, 추정·기억 기재는 재조사로 교체하거나 삭제한다(`shared/판례-인용-정책.md` 3.). 병합 사건은 원문 표제의 병합번호까지 적었는가(예: "2022다302497, 302503 판결") — 판례DB citation에 병합번호가 없으면(원격 MCP 등) 원문 표제(read 결과 첫 # 줄)로 보충하고, `official-xml`처럼 표제에도 주 번호만 있으면 로컬 `case_db.py`의 citation으로 확인한다(`shared/판례-인용-정책.md` 3.).
- [ ] **별지 사용 권장 항목** — 부동산 표시, 손해 산정 내역, 이자 계산표, 다수 당사자 명단 등은 별지로 분리하면 가독성 ↑.
- [ ] **서면 분량의 적정성** — 핵심 분량 대비 부수 주장이 과도하지 않은지. 분량은 미덕이 아니다.
- [ ] **숫자·금액의 단순 오타** — 본문, 청구취지, 증명방법 사이 금액 일치.
- [ ] **이전 서면과의 정합성** — 답변서·준비서면이라면 직전 서면에서 인정한 사실을 뒤늦게 부인하고 있지 않은가(자백 철회는 까다롭다).
