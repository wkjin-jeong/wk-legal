# 행정쟁송 형식요건 체크리스트

신규 작성 전(선결 게이트)과 초안 완성 후(자체 점검)에 두 번 사용한다. 조문은 모두 ko-law-api(국가법령정보 API)로 확인한 것이며, 의문이 생기면 다시 조회한다.

## A. 선결 게이트 — 작성 전 점검 (하나라도 걸리면 사용자에게 먼저 알린다)

### A-1. 처분성
- [ ] 다투는 대상이 행정소송법 제2조 제1항 제1호의 "처분등"(처분 + 행정심판 재결)에 해당하는가.
- [ ] 단순한 안내·통보·민원 회신·내부 행위가 아닌가(처분성이 의심스러우면 판례를 판례DB로 확인하고, 부정 위험을 사용자에게 알린다).

### A-2. 당사자
- [ ] 피고가 **처분을 한 행정청**인가(행정소송법 제13조) / 피청구인이 처분을 한 행정청(의무이행심판은 신청을 받은 행정청)인가(행정심판법 제17조 제1항). 위임·내부위임 사안에서 처분 명의자 확인.
- [ ] 원고(청구인)에게 법률상 이익이 있는가(행정소송법 제12조, 행정심판법 제13조). 제3자 원고이면 적격 논증 준비.
- [ ] 당사자소송이면 피고가 권리주체(국가·공공단체)로 되어 있는가.

### A-3. 기간 (기산점 증빙을 자료로 확인 — 추측 금지)

| 절차 | 기간 | 근거 |
|---|---|---|
| 취소소송 | 처분등이 있음을 안 날부터 90일(불변기간 — 제20조 제3항) / 있은 날부터 1년(정당한 사유가 있으면 예외 — 제20조 제2항 단서) | 행정소송법 제20조 |
| 재결 경유 취소소송 | 재결서 정본 송달일부터 90일 / 재결이 있은 날부터 1년 | 행정소송법 제20조 |
| 부작위위법확인소송 | 원칙적으로 제소기간 제한 없음. 행정심판 등 전심을 거친 경우 제20조 기간 적용 | 행정소송법 제38조 제2항, 대법원 2009. 7. 23. 선고 2008두10560 판결 |
| 당사자소송 | 법령에 제소기간이 있으면 그 기간(불변기간), 없으면 실체법상 시효 등 검토 | 행정소송법 제41조 |
| 개별법 전치 사건 | 해당 법률의 특례 우선(예: 심사·심판청구 결정의 통지를 받은 날부터 90일, 불변기간) | 국세기본법 제56조 제3항·제6항 |
| 취소심판 | 알게 된 날부터 90일(불변기간 — 제27조 제4항) / 있었던 날부터 180일(정당한 사유가 있으면 예외 — 제27조 제3항 단서) | 행정심판법 제27조 |
| 이의신청 | 처분을 받은 날부터 30일 | 행정기본법 제36조 제1항 |
| 이의신청 후 쟁송 | 결과 통지일(또는 통지기간 만료일 다음 날)부터 90일 | 행정기본법 제36조 제4항 |

- [ ] 기산점(송달일)이 자료로 확인되는가.
- [ ] 무효등확인심판·부작위 의무이행심판은 기간 제한 없음(행정심판법 제27조 제7항). 무효확인소송은 제소기간 제한 없음 — 기간 도과 사건의 대안 노선으로 검토.
- [ ] 고지 하자가 있으면 행정심판법 제27조 제5항(오고지)·제6항(불고지) 적용 검토.

### A-4. 전심절차
- [ ] 행정심판 임의주의가 원칙(행정소송법 제18조 제1항 본문)이나, 개별 법률이 필요적 전치를 정하고 있는가(국세기본법상 심사·심판청구, 공무원 징계의 소청 등 — 해당 법률을 ko-law-api로 확인).
- [ ] 필요적 전치 사건이면 전치 충족(재결 존재) 또는 예외 사유. 제소기간은 A-3의 개별법 전치 사건 행(해당 법률의 기산점)을 적용한다.

### A-5. 관할
- [ ] 행정소송: 피고 소재지 관할 행정법원(행정소송법 제9조 제1항, 무효등확인·부작위위법확인은 제38조, 당사자소송은 제40조로 준용). 중앙행정기관 등이 피고면 서울행정법원에도(제9조 제2항), 부동산·특정 장소 관계 처분은 그 소재지 행정법원에도(제9조 제3항) 제기 가능. 행정법원 미설치 지역은 해당 지방법원 본원, 춘천지방법원 강릉지원 관할구역은 강릉지원(법원조직법 부칙<법률 제4765호> 제2조).
- [ ] 행정심판: 처분청에 따른 소관 행정심판위원회(중앙행정심판위원회/시·도 행정심판위원회 등).

## B. 서면별 필수 기재사항

### B-1. 소장
- [ ] 당사자·법정대리인(소송대리인) 표시
- [ ] 청구취지 — 처분의 특정(처분청·처분일자·처분 내용, 필요시 문서번호)
- [ ] 청구원인 — 처분 경위(절차 경과 포함), 위법사유, 결론
- [ ] 증명방법(처분서·송달 증빙·사전통지서·재결서 등 절차 서증 포함)
- [ ] 작성일, 법원 표시
- [ ] 가집행 선고를 구하지 않았는가(항고소송 — 성질상 부적합)

### B-2. 심판청구서 (행정심판법 제28조)
- [ ] 청구인 이름·주소, 피청구인과 위원회
- [ ] 처분의 내용, **처분이 있음을 알게 된 날**
- [ ] 청구 취지와 이유
- [ ] 행정심판 고지 유무와 그 내용
- [ ] 부작위 청구: 전제가 되는 신청의 내용과 날짜(제28조 제3항)
- [ ] 대리인(대표자·선정대표자) 청구: 그 이름과 주소(제28조 제4항)
- [ ] 서명 또는 날인(제28조 제5항)

### B-3. 집행정지 신청서
- [ ] 본안 계속 사실(사건번호) — 소송의 경우
- [ ] 정지 대상의 선택(효력/집행/절차속행)과 보충성 단서 검토
- [ ] 손해 요건의 법문이 절차에 맞는가(소송 "회복하기 어려운 손해" / 심판 "중대한 손해")
- [ ] 소명 자료(소갑호증) 대응
- [ ] 심판: 피청구인에게 심판청구서를 내고 동시에 신청하면 심판청구서 사본·접수증명서 첨부(행정심판법 제30조 제5항 단서)
- [ ] 정지 기간 문언(판결 선고 시까지 / 재결이 있을 때까지)과 수신(법원 / ○○행정심판위원회)

### B-4. 의견제출서·이의신청서
- [ ] 대상 처분(예정 처분)의 표시가 통지서와 일치
- [ ] 제출 기한 확인
- [ ] 이의신청이면 행정기본법 제36조 제8항의 적용 제외 사항 여부
- [ ] 이의신청서 기재사항(행정기본법 시행령 제11조 제1항 — 성명·생년월일·주소·연락처, 처분의 내용과 처분을 받은 날, 이의신청 이유)

### B-5. 항소이유서·상고이유서 (민사소송법 준용 — 행정소송법 제8조 제2항)
- [ ] 항소이유서: 항소장에 항소이유를 적지 않았으면 항소기록 접수 통지(민사소송법 제400조 제3항)를 받은 날부터 40일 이내(제402조의2 제1항, 1회에 한해 1개월 연장 — 같은 조 제2항). 기간 내 미제출이면 항소 각하 결정(제402조의3 제1항 — 직권조사 사유가 있거나 항소장에 항소이유가 있으면 예외). 제402조의2·제402조의3은 그 개정법 시행일(2025. 3. 1.) 후 최초로 항소장이 제출된 사건부터 적용된다(민사소송법 부칙<법률 제20003호, 2024. 1. 16.> 제1조·제2조).
- [ ] 상고이유서: 상고장에 상고이유를 적지 않았으면 소송기록 접수 통지(제426조)를 받은 날부터 20일 이내(제427조). 미제출이면 상고 기각(제429조 — 직권조사 사유가 있으면 예외).
- [ ] 행정소송 상고사건에도 상고심절차에 관한 특례법이 적용된다(같은 법 제2조) — 상고이유가 같은 법 제4조 제1항 각 호의 사유를 포함하도록 구성한다.
- [ ] 피고가 상고하면 원고는 상고이유서를 송달받은 날부터 10일 이내에 답변서를 제출할 수 있다(민사소송법 제428조 제2항).
- [ ] 기산점(통지일·송달일)이 자료로 확인되는가 — 불명확하면 추측하지 말고 되묻는다.

## C. 완성 후 공통 점검
- [ ] 인용 법령이 기준 시점(SKILL.md 4.2 — 제재처분은 위반행위일과 경한 변경 법령) 시행본인가(ko-law-api get-asof 확인 — 개정이 있으면 구법 표기).
- [ ] 판례 인용이 모두 판례DB 또는 판례 검색 스킬에서 확인된 것인가(추정 인용 0건 — `shared/판례-인용-정책.md` 3.). 법리 설시는 요약·재진술 없이 원문을 옮겼는가(따옴표 없는 전재 + 괄호 출처가 기본, 큰따옴표 직접 인용도 가능 — `shared/판례-인용-정책.md` 2.2).
- [ ] 재결례·결정례를 인용했다면 기관·일자·번호를 원문(PDF) 머리에서 확인했는가(bigcase 카드·발췌의 기관명 전재 금지 — "국민권익위원회"만 보이거나 미확인이면 `[재결 기관 확인 필요]`). 권익위 시정권고·의견표명 등 구속력 없는 자료를 구속력 있는 판단처럼 쓰지 않았는가.
- [ ] 호칭 통일 — 소송은 원고/피고, 심판은 청구인/피청구인, 집행정지는 신청인/피신청인.
- [ ] 본문 인용 증거번호와 증명방법(소명방법) 목록의 일치.
- [ ] 종결 문구 — 소송 "라는 판결을 구합니다" / 심판 "라는 재결을 구합니다" / 집행정지 "라는 결정을 구합니다".
- [ ] 기간 관련 기재(안 날·송달일)가 증거와 함께 본문에 들어 있는가.
