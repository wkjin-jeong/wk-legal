# hwpx(한글) 출력 정책 (공통)

서면 markdown 초안을 한글 문서(.hwpx)로 만드는 규칙의 canonical 정의. 변환은 `shared/hwpx/render.py`(표준 라이브러리만 사용)가 하고, 각 drafting skill은 이 문서만 가리킨다.

## 1. 범위와 시점

- **사용자가 요청할 때만 만든다** — "한글 파일로", "hwpx로 출력", "한글 양식에 넣어 줘" 등. 요청이 없으면 markdown만 낸다.
- **원본은 markdown이다.** 검토·수정은 md에서 끝내고, 확정된 md에서 hwpx를 만든다. 변환기는 내용을 고치지 않는다 — hwpx를 고칠 일이 생기면 md를 고쳐 다시 만든다.
- **대상 서면**: 민사·행정·형사 서면이다 — 소장·답변서·준비서면·상소 서면·각종 신청서, 행정심판 청구서·보충서면·집행정지 신청서·의견제출서·이의신청서, 변호인의견서·구속·보석 서면·변론요지서·상소이유서·고소장·고발장. 자문의견서는 레터헤드 구조가 달라 아직 연결하지 않았다. 표두·서명부가 없는 낭독용 서면(최후변론 등)은 표제와 본문만 들어간다.

## 2. 실행

```bash
python3 <플러그인>/shared/hwpx/render.py build "<초안.md>"
```

- 스킬 폴더 기준 경로는 `../../shared/hwpx/render.py`다. 셸에서 보이지 않으면(Cowork 등 VM) 첫 명령에서 찾아 그 절대경로를 이후 명령에 쓴다: `R=$(find "$HOME" -maxdepth 8 -path '*/shared/hwpx/render.py' 2>/dev/null | head -1); echo "$R"`.
- **변환 대상은 제출본이다** — 서면 전문(표제부터 법원 표시까지, 그 뒤의 별지)만 담은 md. 작성 메모, 【중대 지적】·변경 사항 논평, 판례 패키지, 검토 표처럼 제출하지 않는 내용이 같은 파일에 있으면 그것을 뺀 md를 `<초안 이름>-제출본.md`로 저장해 변환한다. 변환기는 표제 바로 뒤의 `>` 메모, 법원 표시 뒤의 별지 아닌 내용, 번호 항목으로 시작하는 부분 초안을 거부한다.
- **출력은 변환한 md와 같은 폴더, 같은 이름의 `.hwpx`**다(`-o`로 바꿀 수 있다).
- **같은 이름의 hwpx가 있으면 덮어쓰지 않는다.** 변환기가 거부하므로, 사용자가 한글에서 고친 파일일 수 있음을 알리고 새 이름(`-o`)으로 낼지, 덮어쓸지(`--force`) 묻는다.
- 의뢰인 측(원고측·피고측)은 모두문·서명의 "○○의 소송대리인·대리인·변호인"에서 판단한다. 당사자에 피의자·피고인이 있고 고소인·고발인이 없으면 형사 변호로 보아 피고측이다(구속적부심·보석의 '청구인'도 같다). 판단하지 못하면 프로필의 기본 양식을 쓰고, 측별 양식이 있는 프로필이면 사용자에게 확인한다(`--side 원고측|피고측`).
- 실행 결과의 `경고:`(번호 불일치·번호 없는 제목 등)는 사용자에게 그대로 전한다. `오류:`(구조 오류·초안 글자 누락)가 있으면 그 hwpx를 결과물로 내지 않고 원인을 보고한다.

## 3. 초안 markdown의 형식

변환기는 각 skill 템플릿의 표준 골격을 그대로 읽는다. 따로 맞출 것은 아래뿐이다.

| 요소 | markdown | hwpx |
|---|---|---|
| 표제 | 첫 줄(`# 준 비 서 면` 등) | 양식의 표제(`준 비 서 면`처럼 한 글자씩 띄운 표제만 붙이고 낱말 띄어쓰기는 둔다) |
| 사건·당사자 | `사    건   2026가합…`, `원    고   ○○○`, `피 의 자`·`죄    명`·`수    신` 등, 이어지는 주소 줄은 들여 쓴다. `[ 사건명 ] …`·`처분의 표시: …`도 한 줄로 | 양식의 당사자 줄(2~4글자 라벨은 탭 배분), 이음 줄은 줄바꿈 |
| 모두문·「다 음」 | 모두문 한 단락, `다 음` 줄 | 양식의 모두문·「다 음」 자리 |
| 항목 표제 | 줄 앞 번호 `1.`·`가.`·`1)`·`가)`·`(1)`·`(가)` (`#` 개수는 보지 않는다) | **한글 개요 1~6 — 자동 번호**(초안의 번호 글자는 지운다) |
| 본문 | 한 줄이 한 단락 | 본문 스타일, 앞 공백 |
| 강조 | `**…**` | 프로필의 강조 모양 |
| 인용 | `> …`(이어진 줄은 한 덩어리) | 프로필 `body.quote` — `indent` 들여 쓴 본문(기본) / `box` 테두리 상자(1×1 표) / `plain` 일반 본문 |
| 표 | 파이프 표 — 구분선 `:---:` 가운데, `---:` 오른쪽, `:---` 왼쪽, `---` 양쪽 | 한글 표. 첫 행은 머리행, 첫 칸이 `합계`·`계`인 마지막 행은 합계 행 |
| 그림 | `![캡션](초안 기준 상대경로)` — PNG·JPEG | 본문 폭 안으로 줄인 그림 + 캡션 |
| 중간제목 | `증 명 방 법`처럼 띄어 쓴 짧은 제목(`**`·`#` 무관), 번호 없는 짧은 `#` 제목(`## 변경된 청구취지`) | 중간제목 스타일. 번호 없는 긴 `#` 제목은 굵은 본문 |
| 목록 구역 | 제목에 청구취지·신청취지·항소취지 등이 들어간 구역 / 증명방법·첨부서류·당사자 등이 들어간 구역 | 번호는 글자 그대로(자동 번호 아님). 청구취지 계열은 번호 줄만 항목이고 결어(`라는 판결을 구합니다.`)는 본문, 증명방법 계열은 모든 줄이 항목. 두 계열의 줄간격·앞 공백은 프로필 `lists`·`lists.claims` |
| 날짜·서명·수신처 | 날짜 줄 → 대리인·법인·`담당변호사 …` 줄(또는 한 줄 `피의자의 변호인 변호사 ○○○ (인)`) → `○○법원 귀중`·`○○경찰서 귀중`·`검사 ○○○ 귀하` | 양식의 서명 블록(한 쪽에 묶는다). 한 줄 서명은 역할·법인·변호사로 나누고 날인 표시 `(인)`은 뺀다. `○○` 자리표시는 프로필 서명자로 채운다. 수신처 줄이 없는 서면(의견제출서 등 — 수신은 머리의 `수    신`)은 끝부분 날짜 뒤를 서명으로 본다 |
| 별지 | 법원 줄 다음 `---` 뒤 | 새 쪽, 번호는 1부터 다시 |

- **번호 연번**: 자동 번호는 초안의 번호를 따르지 않고 다시 센다. 같은 단계의 번호가 1·가로 돌아가면(신청취지·신청이유처럼 구역마다 1.부터 쓰는 서면) 그 자리에서 새 번호열을 1부터 시작한다. 그 밖에 연번이 아닌 번호(건너뛰기·0.)는 변환기가 경고하므로, 본문 안의 항목 참조("위 2.의 나.")가 맞는지 확인한다.
- **지원하지 않는 것**: 표의 셀 병합, 각주(`[^1]`은 글자 그대로 남는다), 글상자. 이런 요소가 필요하면 hwpx를 만든 뒤 한글에서 고치도록 안내한다.

## 4. 프로필과 양식

- **프로필**은 양식 파일과 서식 수치(표 선·여백, 그림 캡션, 강조, 서명자)를 담은 `profile.json`이다. 다음 순서로 찾고, 없으면 플러그인 기본값(`shared/hwpx/기본프로필.json` + 기본양식)을 쓴다.
  1. `--profile <폴더|파일>`
  2. 환경변수 `WK_LEGAL_HWPX_PROFILE`
  3. 초안 폴더(와 현재 폴더)에서 위로 올라가며 `.wk-legal/hwpx/profile.json` — **작업 폴더 최상위(예: 진행사건 폴더)에 한 번 두면 그 아래 모든 사건에 쓰인다**(Cowork VM에서도 마운트한 폴더 안이면 찾는다)
  4. `~/.config/wk-legal/hwpx/profile.json`(VM에는 `~/.config`가 없다)
- `python3 render.py where "<초안.md>"`로 쓰일 프로필과 양식을 확인한다.
- **최종 요약에 한 줄**: 쓴 프로필 이름과 양식(측), 기본값을 썼으면 그 사실. 그리고 "한글에서 열어 쪽 나눔·표 폭·그림 위치를 확인할 것" — 쪽 나눔은 한글이 열 때 다시 계산하므로 변환기가 검증할 수 없다.
- **프로필은 로컬 자료다.** 사무소명·담당변호사·양식 파일을 플러그인 저장소나 다른 사건 산출물로 옮기지 않는다.

### 4.1 사무소 양식으로 프로필 만들기

1. 한글 양식(.hwpx)에 표지를 넣는다: `python3 render.py mark "<양식.hwpx>" -o "<표지본.hwpx>"`. 스타일 이름(문서제목·본문·개요 n·중간제목·법원)과 문단 모양으로 역할을 추정해 `{{표제}}`·`{{당사자}}`·`{{모두문}}`·`{{다음}}`·`{{본문}}`·`{{날짜}}`·`{{대리인}}`·`{{법인}}`·`{{변호사}}`·`{{법원}}`을 넣는다. 찾지 못한 표지는 한글에서 해당 문단에 직접 적는다. 표지 문단의 문단·글자 모양이 결과물에 그대로 쓰인다.
2. 양식에는 스타일 `본문`·`바탕글`·`개요 1`(~`개요 6`)이 있어야 하고, 표·중간제목·문서제목 스타일은 있으면 쓴다. 이름이 다르면 프로필 `styles`로 연결한다.
3. `profile.json`에는 기본값과 다른 항목만 적는다(나머지는 기본프로필을 따른다).

```json
{
  "name": "사무소명",
  "templates": { "원고측": "원고측.hwpx", "피고측": "피고측.hwpx", "기본": "원고측.hwpx" },
  "signers": { "firm": "법무법인 ○○", "lawyers": ["홍길동"], "lawyer_line": "담당변호사    {name_spaced}" },
  "body": { "emphasis": ["bold", "underline"], "quote": "box" },
  "quote_box": { "border": "0.5 mm" },
  "table": { "outer": "0.5 mm", "inner": "0.12 mm", "header_rule": "0.5 mm", "total_rule": "0.5 mm" },
  "picture": { "border_hwpunit": 141, "caption_side": "TOP", "caption_native": true, "caption_format": "【{}】" },
  "lists": { "line_spacing": 220, "lead_spaces": 7, "claims": { "line_spacing": 250, "lead_spaces": 8 } }
}
```

- `templates`의 경로는 profile.json 기준이다. 측별 양식이 없으면 `기본` 하나만 둔다.
- 수치 단위: 여백은 HWPUNIT(1mm ≈ 283), 선 굵기는 `"0.5 mm"` 문자열, `border_hwpunit` 141 ≈ 0.5mm.
- `lawyer_line`의 `{name}`은 이름 그대로, `{name_spaced}`는 글자 사이를 띄운 이름이다.
